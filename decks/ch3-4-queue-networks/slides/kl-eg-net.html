网络平均时延

T = (1/6) [5/(8−5) + 4/(6−4)] = (1/6)(1.667 + 2) = 0.611 s。

各路径

A→B：1/(8−5) = 0.333 s；B→C：1/(6−4) = 0.5 s；A→C：0.833 s。加权平均 (3×0.833 + 2×0.333 + 1×0.5)/6 = 0.611 ✓

哪里是瓶颈？

B→C：ρ = 0.667；A→B：0.625。把 B→C 升到 8：T 降到 0.444 s。

【4 分钟】 用 Kleinrock 公式，算一个具体的小网络。三个节点 A、B、C，两条链路 A 到 B，B 到 C。三条流：A 到 C 每秒 3 个分组，必须经过 B；A 到 B 每秒 2 个；B 到 C 每秒 1 个。链路速率：A 到 B 的服务率 μ 是每秒 8 个分组；B 到 C 是每秒 6 个。进入网络的总到达率 γ 等于 3 加 2 加 1，等于每秒 6 个。 第一步，把各流叠加到各链路上：A 到 B 的链路，承载 A 到 C 的流 3 和 A 到 B 的流 2，共 5 个每秒；B 到 C 的链路，承载 A 到 C 的流 3 和 B 到 C 的流 1，共 4 个每秒。 第二步，代入公式：T 等于六分之一，乘 (5 除以 (8 减 5)，加上 4 除以 (6 减 4))，等于六分之一乘 (1.667 加 2)，等于 0.611 秒。 再看各条路径：A 到 B：1 除以 (8 减 5)，0.333 秒；B 到 C：1 除以 (6 减 4)，0.5 秒；A 到 C，要走两条链路，0.833 秒。按流量加权平均：(3 乘 0.833，加 2 乘 0.333，加 1 乘 0.5) 除以 6，也是 0.611 秒，和网络公式一致。 哪里是瓶颈？B 到 C 的链路 ρ 是 0.667，A 到 B 是 0.625，都不低。如果把 B 到 C 的链路速率提到每秒 8 个，网络平均时延降到 0.444 秒——降了 27%。 [验算：5/3 + 4/2 = 3.667；3.667/6 = 0.611；4/(8−4) = 1，(1.667 + 1)/6 = 0.444。]
