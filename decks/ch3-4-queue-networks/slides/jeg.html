算法：每个节点按 M/M/1 算：N = ρ / (1 − ρ)。全网人数相加，再用 Little 定理，除以外部进入率 γ = 1。

两种算法：先算全网人数 2.5 个，再除以 γ；或者逐站算“访问次数 × 每次时延”再相加。两种方法得到同一个数。

全网 Little 定理：T = N/γ = 2.5 s，和逐站算出的一样。

【3 分钟 · 重点】 CPU、I/O 例子：λ = (4, 3)，μ = (8, 5)，所以 ρ = (0.5, 0.6)；N_1 = ρ/(1 − ρ) = 1，N_2 = 1.5，N = 2.5；全网的 T = N/γ = 2.5/1 = 2.5 秒。注意分母是外部进入率 γ，不是 CPU 与 I/O 的到达率之和：一个任务多次访问 CPU，不能重复计数。 交叉验算，用另一种方法：每个任务访问 CPU 4 次，每次的时延是 1/(8 − 4) = 0.25 秒，一共 1 秒；访问 I/O 3 次，每次 1/(5 − 3) = 0.5 秒，一共 1.5 秒；合计 2.5 秒。完全一致。 这里的“每次时延”是 M/M/1 的时延，所以要求各节点的人数分布和孤立的 M/M/1 一样：这正是 Jackson 定理保证的。 [验算：事件模拟 60 万个任务：T = 2.507 秒，N_1 = 1.000，N_2 = 1.509。]
