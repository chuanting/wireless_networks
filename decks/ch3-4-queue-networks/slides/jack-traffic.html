第三部分 · Jackson 定理

流量方程：每个节点到底有多忙？

第一步：流量方程（每个节点的总到达率）

节点 i 的总到达 = 外部到达 + 别的节点送来的：

λi = γi + Σj λj Pji

（稳态：流进多少、流出多少。）是一组线性方程，一定有唯一解（因为有人会离开）。

CPU / I/O 例：外部只进 CPU，速率 γ；P(CPU→I/O) = p2，P(I/O→CPU) = 1。

λ1 = γ + λ2，　λ2 = p2 λ1

λ1 = γ / p1，　λ2 = p2 γ / p1

数字：γ = 1 个/秒，p1 = 0.25

λ1 = 1/0.25 = 4 个/秒；λ2 = 0.75 × 4 = 3 个/秒。

访问次数

每个任务平均访问 CPU 4 次（λ1/γ）、I/O 3 次。

直觉

只有 25% 的概率离开，所以平均要“绕”4 圈——节点的到达率比外部到达率大得多。

【3 分钟 · 重点】 第一步：求每个节点的总到达率，叫流量方程。 节点 i 的总到达率 λ_i，来源有两个：一是外部直接到达的 γ_i；二是别的节点 j 服务完，转过来的：节点 j 的总到达率 λ_j，乘上从 j 转到 i 的概率 P_ji，对所有 j 求和。稳态时，流进多少、流出多少，所以 λ_i 等于 γ_i 加上这个求和。这是一组线性方程，因为总有任务会离开，所以有唯一解。 用在 CPU、I/O 的例子上：外部只进 CPU，速率 γ。CPU 的总到达 λ_1，等于外部到达 γ，加上 I/O 送回来的 λ_2；I/O 的总到达 λ_2，等于 CPU 的总到达 λ_1 乘 p_2。解得：λ_1 等于 γ 除以 p_1；λ_2 等于 p_2 乘 γ 除以 p_1。 代入数字：γ 等于每秒 1 个，p_1 等于 0.25，也就是每个任务有 25% 的概率在 CPU 处理完后离开。那么 λ_1 等于 1 除以 0.25，等于每秒 4 个；λ_2 等于 0.75 乘 4，等于每秒 3 个。 直觉：每个任务离开的概率只有 25%，所以平均要在 CPU 和 I/O 之间绕 4 圈——每个任务平均访问 CPU 4 次、I/O 3 次。所以 CPU 的到达率，远远大于外部的到达率。 [验算：λ_1 = 1 + 3 = 4；λ_2 = 0.75 × 4 = 3 ✓。]
