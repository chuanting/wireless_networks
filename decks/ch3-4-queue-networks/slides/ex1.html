练习（一）：串联、开放网络与 Kleinrock 公式

①

两个 M/M/1 串联：λ = 3，服务率 5 和 4（个/s）。求两个队列的平均人数、网络平均时延 T，以及两个队列里分别有 2 个和 1 个顾客的概率。

②

节点 1 有外部到达 γ = 2，服务率 10；节点 2 无外部到达，服务率 6。节点 1 服务完以 0.5 去节点 2，其余离开；节点 2 服务完以 0.2 回节点 1，其余离开。求各节点的到达率、平均人数和 T。

③

三条链路的到达率 4、6、2（个/s），服务率 10、10、5，进入网络的总到达率 γ = 8。求网络平均时延；每条链路再加 5 ms 传播时延呢？

【3 分钟 · 参考答案】 ① ρ_1 = 3/5 = 0.6，ρ_2 = 3/4 = 0.75。N_1 = 0.6/0.4 = 1.5；N_2 = 0.75/0.25 = 3；N = 4.5；T = N/λ = 1.5 秒（= 1/(5 − 3) + 1/(4 − 3) = 0.5 + 1）。P(2, 1) = (1 − 0.6) × 0.6^2 × (1 − 0.75) × 0.75 = 0.4 × 0.36 × 0.25 × 0.75 = 0.027。 ② 流量方程：λ_1 = 2 + 0.2 λ_2，λ_2 = 0.5 λ_1。代入：λ_1 = 2 + 0.1 λ_1，所以 λ_1 = 2/0.9 = 2.222，λ_2 = 1.111。ρ_1 = 0.222，ρ_2 = 0.185。N_1 = 0.222/0.778 = 0.286；N_2 = 0.185/0.815 = 0.227；N = 0.513；T = N/γ = 0.513/2 = 0.256 秒。 ③ T = (1/γ) Σ λ/(μ − λ) = (1/8)(4/6 + 6/4 + 2/3) = (1/8)(0.667 + 1.5 + 0.667) = 2.833/8 = 0.354 秒。每条链路加 5 ms：Σ λ d = (4 + 6 + 2) × 0.005 = 0.06，除以 8 得 0.0075 秒，总计 0.3617 秒。 [验算：① 事件模拟 T = 1.496，(2, 1) 的概率 0.0270；② 事件模拟 T = 0.2564 秒。]
