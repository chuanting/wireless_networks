流量（个/s）：A→C 3，A→B 2，B→C 1；进入网络的总到达率 γ = 6

T = (1/6) [5/(8 − 5) + 4/(6 − 4)] = (1/6)(1.667 + 2) = 0.611 s

各路径：A→B 1/(8 − 5) = 0.333 s；B→C 1/(6 − 4) = 0.5 s；A→C 两段相加 0.833 s。按流量加权：(3 × 0.833 + 2 × 0.333 + 1 × 0.5)/6 = 0.611 s，与公式一致。

两种算法得到同一个数：0.611 s。

【4 分钟】 用 Kleinrock 公式算一个具体的小网络。三个节点 A、B、C，两条链路：A 到 B，B 到 C。三条流：A 到 C 每秒 3 个分组，必须经过 B；A 到 B 每秒 2 个；B 到 C 每秒 1 个。链路 A 到 B 的服务率 μ 是每秒 8 个分组；B 到 C 是每秒 6 个。进入网络的总到达率 γ = 3 + 2 + 1 = 6 个每秒。 第一步，把各流叠加到各链路上：A 到 B 的链路，承载 A 到 C 的流 3 和 A 到 B 的流 2，共 5 个每秒；B 到 C 的链路，承载 A 到 C 的流 3 和 B 到 C 的流 1，共 4 个每秒。 第二步，代入公式：T = (1/6) × [5/(8 − 5) + 4/(6 − 4)] = (1/6) × (1.667 + 2) = 0.611 秒。 再看各条路径：A 到 B：1/(8 − 5) = 0.333 秒；B 到 C：1/(6 − 4) = 0.5 秒；A 到 C 要走两条链路，是两段相加，0.833 秒。按流量加权平均：(3 × 0.833 + 2 × 0.333 + 1 × 0.5)/6 = 0.611 秒，和网络公式给出同一个数。 [验算：分组长度一路带着走的事件模拟（400 万个分组）：全网平均时延 0.615 秒，与公式相差 0.6%；A 到 B 0.333，A 到 C 0.849，B 到 C 0.476 秒。各段服务时间独立时是 0.613 秒。]
