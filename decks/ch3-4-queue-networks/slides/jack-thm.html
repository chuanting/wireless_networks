第三部分 · Jackson 定理

Jackson 定理：乘积形式

Jackson 定理（开放网络）

若 ① 外部到达是泊松；② 各节点服务时间独立、指数分布，且所有 ρi = λi/μi < 1，则稳态时各节点顾客数相互独立，且每个节点像一个孤立的 M/M/1：

P(n1, …, nK) = Πi (1 − ρi) ρi 的 ni 次方

于是：Ni = ρi/(1 − ρi)；N = ΣNi；网络平均时延 T = N / Σγi（Little 定理）。

CPU / I/O 例（μ1 = 8，μ2 = 5）

ρ1 = 4/8 = 0.5，ρ2 = 3/5 = 0.6；N1 = 1，N2 = 1.5。

结果

N = 2.5；T = N/γ = 2.5 秒。

交叉验算：按访问次数

CPU：4 次 × 1/(8−4) = 1 s；I/O：3 次 × 1/(5−3) = 1.5 s；合计 2.5 s ✓

事件模拟验证：T ≈ 2.51 s。

【4 分钟 · 重点】 Jackson 定理：如果外部到达是泊松过程；各节点的服务时间是相互独立的指数分布；而且每个节点的 ρ_i 都小于 1，那么在稳态时：各个节点的顾客数相互独立；而且每个节点的顾客数，就像一个孤立的 M/M/1 队列，到达率是流量方程解出的 λ_i。联合分布是乘积形式：P(n_1, ..., n_K) 等于 对 i 连乘 (1 减 ρ_i) 乘 ρ_i 的 n_i 次方。 所以：每个节点的平均顾客数 N_i 等于 ρ_i 除以 (1 减 ρ_i)；整个网络里的平均顾客数是 N_i 的总和；网络的平均时延，用 Little 定理，T 等于 N 除以外部总到达率 Σγ_i。 CPU、I/O 例子：μ_1 等于 8，μ_2 等于 5。λ_1 是 4，λ_2 是 3。所以 ρ_1 等于 0.5，ρ_2 等于 0.6。N_1 等于 1，N_2 等于 1.5，N 等于 2.5。T 等于 2.5 除以 γ，也就是 2.5 秒。 交叉验算，用另一种方法：每个任务访问 CPU 4 次，每次的时延是 1 除以 (8 减 4)，0.25 秒，一共 1 秒；访问 I/O 3 次，每次 1 除以 (5 减 3)，0.5 秒，一共 1.5 秒；合计 2.5 秒。完全一致。我用事件模拟验证过，T 约 2.51 秒。 注意：Jackson 定理给的是联合分布，因而给出平均顾客数和平均时延。下一页说明，它“神奇”在哪里。 [验算：N = 0.5/0.5 + 0.6/0.4 = 1 + 1.5 = 2.5；T = 2.5/1 = 2.5 s。]
