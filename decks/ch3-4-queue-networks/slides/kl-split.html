共用一个队列总比各管各的好：这又是统计复用。

【4 分钟】 用公式比较两种分流办法。节点 A 有一个泊松到达流，速率 λ，分组长度是指数分布，要发给 B。A 和 B 之间有两条一样的链路，服务率都是 μ，ρ = λ/(2μ)。 方案一：随机分流。每个分组独立地掷一个硬币，决定走哪条链路。泊松过程的随机分流性质：每条链路得到速率 λ/2 的泊松流，各是一个 M/M/1。时延 T = 1/(μ − λ/2) = 1/[μ(1 − ρ)]。 方案二：共用一个队列。分组先排在一个队里，哪个服务员空了就取队首，这是 M/M/2。用爱尔兰 C 公式，等待概率 P_Q = 2ρ^2/(1 + ρ)，时延 T = 1/μ + P_Q/(2μ − λ)，化简得 T = 1/[μ(1 − ρ^2)]。 两者之比 T_共用/T_随机 = 1/(1 + ρ)。ρ = 0.5：2/μ 对 1.333/μ；ρ = 0.8：5/μ 对 2.778/μ，快了将近一倍；ρ = 0.9：10/μ 对 5.263/μ。 这又是“统计复用”的好处：两台服务员共用一个队列，不让一台空着、另一台排长队，和 3.2 节的结论一致。 注意：这个比较精确适用于这两种模型，不能套给任意负载均衡策略。如果分组到达时就必须选一条链路，而且选了不能换：按“当前未完成工作量最少”选（知道分组长度）能做到和共用队列同样的时延；按“当前分组个数最少”选就差一些，在 ρ = 0.8 时是 2.95/μ，介于共用队列的 2.77/μ 和随机分流的 4.97/μ 之间。 [验算：事件模拟（300 万个分组）：随机分流 1.999、4.967、9.963（ρ = 0.5、0.8、0.9）；共用队列 1.334、2.770、5.246；未完成工作量最少的分流与共用队列完全相同；个数最少的分流 1.427、2.946、5.458。]
