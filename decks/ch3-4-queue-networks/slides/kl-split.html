第四部分 · Kleinrock

路由分流：随机 vs 计量

例：A 沿两条同样的链路发往 B，怎样分流？

到达：泊松 λ，分组长度指数；两条链路服务率都是 μ；ρ = λ / (2μ)。

方案 1：随机（掷硬币）：两条链路各得到达率 λ/2 的泊松流，各是 M/M/1：

TR = 1/(μ − λ/2) = 1 / [μ(1 − ρ)]

方案 2：计量——送进比特数最少的队列。等价于一个 M/M/2（共用队列）；爱尔兰 C：PQ = 2ρ 的平方/(1 + ρ)：

TM = 1/μ + PQ/(2μ − λ) = 1 / [μ(1 − ρ 的平方)]

TM / TR = 1/(1 + ρ)

数字 ρ = 0.8

TR = 5/μ，TM = 2.78/μ：计量方案快近一倍。

ρ = 0.5

TR = 2/μ，TM = 1.33/μ：快 1/3。

这又是“统计复用”

两条链路共用一个队列，比各管各的好——和 3.2 节的结论一致。

但是（大小要紧）

计量会让各链路的到达不再是泊松，对这种情形，把每条链路当作 M/M/1 的近似较差。

【4 分钟】 用公式比较两种路由分流方法。节点 A 有一个泊松到达流，速率 λ，分组长度是指数分布，要发给 B。A 和 B 之间有两条一样的链路，服务率都是 μ。怎样把分组分配给两条链路？ 方案一：随机，A 每收到一个分组，就掷一个硬币，决定走哪条链路。根据泊松过程的“随机分流”性质，每条链路得到的是速率 λ/2 的泊松流，各是一个 M/M/1。时延 T_R 等于 1 除以 (μ 减 λ/2)，也就是 1 除以 μ 乘 (1 减 ρ)，ρ 是 λ 除以 2μ。 方案二：计量，A 把分组送进比特数最少的那个队列——也就是工作量最小的队列。可以证明，这和一个有两个服务员的 M/M/2 系统，所有顾客共用一个队列，是等价的。用爱尔兰 C 公式，等待概率是 2ρ 平方除以 (1 加 ρ)，时延 T_M 等于 1/μ，加上等待概率除以 (2μ 减 λ)，化简得 1 除以 μ 乘以 (1 减 ρ 平方)。 两者之比：T_M 除以 T_R，等于 1 除以 (1 加 ρ)。ρ 等于 0.8 时，T_R 是 5/μ，T_M 是 2.78/μ，计量方案快了将近一倍。 这又是“统计复用”的好处：两条链路共用一个队列，不让一条链路空着、另一条排长队。 但是有一个细节：计量会破坏各链路到达过程的泊松性质，这时，把每条链路当作 M/M/1 的近似，精度较差——所以独立性近似的准确度，也受服务规则影响。 [验算：T_M = 1/μ + C/(2μ−λ)，C = 2ρ²/(1+ρ)，2μ−λ = 2μ(1−ρ)：T_M = (1/μ)[1 + ρ²/((1+ρ)(1−ρ))] = 1/(μ(1−ρ²))。]
