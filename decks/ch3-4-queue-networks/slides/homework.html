六道小题，检验一下

① 串联

两个 M/M/1 串联：λ = 3，μ1 = 5，μ2 = 4（个/秒）。求 N1、N2、网络平均时延 T，以及联合概率 P(n1 = 2, n2 = 1)。

② 开放网络

节点 1：外部 γ1 = 2，μ1 = 10；节点 2：μ2 = 6，无外部到达。1 → 2 概率 0.5（其余离开）；2 → 1 概率 0.2（其余离开）。求各节点 λ、N、网络 T。

③ Kleinrock 公式

三条链路 λ = (4, 6, 2) 个/秒，μ = (10, 10, 5)，进入网络的总到达率 γ = 8。求网络平均时延；若每条链路再加 5 ms 传播时延呢？

④ 路由分流

两条相同链路，ρ = λ/(2μ) = 0.6。求随机分流与计量分流的时延之比；以 1/μ 为单位各是多少？

⑤ Burke 的含义

M/M/1，λ = 3，μ = 4。离开过程是什么过程？速率多少？若观察到最近 1 秒内连续离开了 5 个顾客，能否说明现在队列很长？为什么？

⑥ CPU / I/O

γ = 1，任务处理完 CPU 后以 0.5 的概率离开，另 0.5 去 I/O，I/O 后回 CPU；μCPU = 5，μI/O = 4。求 λ 和每个任务的访问次数、N、T。

【0.5 分钟 · 参考答案，课上不必讲】 ① ρ_1 = 3/5 = 0.6，ρ_2 = 3/4 = 0.75。N_1 = 0.6/0.4 = 1.5；N_2 = 0.75/0.25 = 3；N = 4.5；T = N/λ = 1.5 秒（= 1/(5−3) + 1/(4−3) = 0.5 + 1）。P(2, 1) = (1−0.6)×0.6² × (1−0.75)×0.75 = 0.4×0.36×0.25×0.75 = 0.027。 ② 流量方程：λ_1 = 2 + 0.2 λ_2；λ_2 = 0.5 λ_1。代入：λ_1 = 2 + 0.1 λ_1 → λ_1 = 2/0.9 = 2.222；λ_2 = 1.111。ρ_1 = 0.222，ρ_2 = 0.185。N_1 = 0.222/0.778 = 0.286；N_2 = 0.185/0.815 = 0.227；N = 0.513；T = N/γ = 0.513/2 = 0.256 秒。 ③ T = (1/γ) Σ λ/(μ−λ) = (1/8)(4/6 + 6/4 + 2/3) = (1/8)(0.667 + 1.5 + 0.667) = 2.833/8 = 0.354 秒。加传播：Σ λ d = (4+6+2)×0.005 = 0.06，0.06/8 = 0.0075 秒，总计 0.3617 秒。 ④ T_R = 1/(μ(1−ρ)) = 2.5/μ；T_M = 1/(μ(1−ρ²)) = 1/(0.64μ) = 1.5625/μ。之比 = 1/(1+ρ) = 0.625。 ⑤ 离开过程是速率 λ = 3 个/秒的泊松过程（Burke 定理）。不能：Burke 定理说，队列长度与过去的离开过程独立，所以“连续离开 5 个”不提供关于当前队长的任何信息。 ⑥ 流量方程：λ_CPU = 1 + λ_IO，λ_IO = 0.5 λ_CPU → λ_CPU = 2，λ_IO = 1。访问次数：CPU 2 次，I/O 1 次。ρ_CPU = 2/5 = 0.4，ρ_IO = 1/4 = 0.25。N = 0.4/0.6 + 0.25/0.75 = 0.667 + 0.333 = 1；T = N/γ = 1 秒（= 2×1/(5−2) + 1×1/(4−1) = 0.667 + 0.333）。 [验算：③ 17/6 = 2.833；② 2/0.9 = 2.2222。]
