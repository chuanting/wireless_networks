自己动手：验证网络的公式

基础

验证 Burke 定理

模拟 M/M/1（λ = 0.5，μ = 1），记录离开时刻，统计离开间隔的平均与 CV；再把服务时间换成固定值（M/D/1）对比。

检验：M/M/1 的 CV ≈ 1.00；M/D/1 的 CV ≈ 0.87。

中级

串联与反馈网络

模拟两个 M/M/1 串联（λ = 2，μ1 = 4，μ2 = 3），再模拟 CPU / I/O 反馈系统（γ = 1，p1 = 0.25，μ = 8、5）。

检验：串联 T ≈ 1.5 s；反馈系统 T ≈ 2.5 s；与 Jackson 公式对照。

进阶

检验独立性近似

模拟两条链路串联、分组长度在两处相同，ρ = 0.3、0.5、0.8，与 Kleinrock 公式对比；再加入第二条流汇合，看误差如何变化。

检验：相同长度、单流：+6%、+3%、−16%；汇合后误差应减小。

想挑战更多？实现一个封闭网络（固定 M 个顾客在两个队列间循环），统计各状态概率，与乘积形式对比。

【选做 · 课上只需 1 分钟介绍】 这页是给想动手的同学准备的，不在课上做。 基础：验证 Burke 定理。模拟一个 M/M/1，λ 等于 0.5，μ 等于 1，记录每个顾客的离开时刻；统计相邻离开间隔的平均值，和波动系数 CV。再换成固定服务时间 M/D/1 对比。M/M/1 的 CV 应该约等于 1，M/D/1 约 0.87。（老师试过：0.9993 和 0.867。） 中级：模拟串联和反馈网络。两个 M/M/1 串联，λ 等于 2，μ_1 等于 4，μ_2 等于 3，T 应该约 1.5 秒；再模拟 CPU、I/O 反馈系统，γ 等于 1，p_1 等于 0.25，μ_1 等于 8，μ_2 等于 5，T 应该约 2.5 秒，和 Jackson 公式对照。（老师试过：1.49 和 2.51。） 进阶：检验独立性近似。模拟两条链路串联，分组长度在两处相同；ρ 取 0.3、0.5、0.8，和 Kleinrock 公式比较，应该是 +6%、+3%、−16%；然后加入第二条流，在第二条链路上汇合，看误差怎样变化。 更进一步：实现封闭网络，固定 M 个顾客，在两个队列之间循环，统计各个状态的概率，和乘积形式对比。 [提示：这些练习不要求提交，愿意做的同学可以课后找老师交流。]
