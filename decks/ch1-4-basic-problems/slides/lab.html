实验：看看你的手机和电脑用了哪些协议

目标

给出你的电脑和手机上网用到的协议名称、版本号、主要功能，以及有关的地址编号、端口号；写出实验的方法和使用的工具。

工具

抓包：Wireshark、tcpdump；看地址和路由：ip addr、ip route；看连接：ss -tn；查域名：dig；看路径：traceroute；看协议版本：curl -v。

记录

按层记：链路层（Wi-Fi 的标准、MAC 地址）；网络层（IPv4 或 IPv6、地址、TTL）；运输层（TCP 或 UDP、端口号）；应用层（DNS、HTTP 的版本、TLS 的版本）。

用本课每一讲的概念，在真实的抓包里找一遍。

【课后实验 · 1 分钟介绍】 参考课件给的实验：试给出利用 PC 机和手机上网使用的协议名称、版本号、主要功能和有关的地址编号、端口号，给出实验的方法和工具。 一个可行的做法：在电脑上打开抓包软件 Wireshark，浏览一个网页，再停下来看：最底下是链路层，Wi-Fi 或以太网，能看到 MAC 地址；往上是 IP，IPv4 还是 IPv6，源和目的 IP 地址，TTL 是多少；再往上是 TCP 或者 UDP，端口号：对方通常是 443 或者 80，自己是一个临时的大端口号；再往上是应用层：DNS 查询、TLS 握手（看版本）、HTTP 的版本。用 ip addr、ip route 看自己的地址和路由，用 ss -tn 看当前的 TCP 连接，用 dig 看域名解析，用 traceroute 看路径，用 curl -v 看和一个网站协商出的 HTTP 和 TLS 版本。 手机的做法类似：连到电脑开的热点上抓包，或者在系统设置里看网络信息。 做完以后，可以对着这门课每一讲的概念，在抓到的包里找一遍：组帧、差错检测、TTL、窗口、端口、拥塞控制。 [这是一个操作实验，不在课上做，也没有标准答案；命令是常见的 Linux 命令，不同系统的写法略有差别。]
