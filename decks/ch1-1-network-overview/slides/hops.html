两套地址：IP 地址全程不变，帧地址每一跳都换

帧头：A → R1

IP 头：A → B

帧头：R1 → R2

IP 头：A → B

帧头：R2 → B

IP 头：A → B

链路上的帧头每一跳都重新封装；IP 头里的源地址和目的地址从 A 到 B 保持不变

IP 地址指出最终的目的地，从 A 到 B 保持不变；帧头里的地址只管这一段链路的下一跳，每过一个路由器就换一次。

路由器收到帧，拆掉帧头，按 IP 地址查路由表，再装上下一段链路的帧头。

【3 分钟】 主机 A 要给主机 B 发分组，中间经过两个路由器。看每一段链路上的头。IP 头里的源地址是 A，目的地址是 B，从 A 一路到 B 不变：它指出最终的目的地。帧头里的地址不同：A 到路由器 1 的帧，帧头是 A → R1；路由器 1 到路由器 2 的帧，帧头是 R1 → R2；路由器 2 到 B 的帧，帧头是 R2 → B。帧头里的地址只管这一段链路的下一跳。 路由器收到一个帧，先拆掉帧头，取出分组，按分组的 IP 目的地址查路由表，找到下一跳，再装上下一段链路的帧头发出去。所以需要两套地址：IP 地址负责“去哪”，帧地址负责“这一跳交给谁”。 细节：IP 头里的生存时间（TTL）每过一跳减 1，校验和也要更新；经过地址转换（NAT）的设备时 IP 地址也会改变。这里只说地址的分工。
