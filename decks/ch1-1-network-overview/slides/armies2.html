【3 分钟】 方案二：1 队一次派出 n 个信使，带同一句话“周六晚 8 点进攻，不必回复”，然后按时进攻；2 队只要收到其中任何一个，也按时进攻。这个方案放弃了“确认”，换来了“再多派几个，成功的概率就越高”。 设每个信使被抓获的概率 p = 0.3。1 队孤军进攻，当且仅当 n 个信使全被抓获，概率 p 的 n 次方：n = 1 是 0.3，n = 2 是 0.09，n = 3 是 0.027，n = 5 是 0.0024，n = 8 是 0.0001。两队同时进攻的概率是 1 − p^n：n = 3 时 97.3%。 但概率永远不会等于 0。这说明：在不可靠的链路上，没有哪种协议能让双方百分之百确定；实际的协议退一步，约好规则，让成功的概率足够高。TCP 的重传、确认、超时，就是这样的规则。 [验算：事件模拟，p = 0.3 时孤军进攻的比例与 p 的 n 次方一致。]
