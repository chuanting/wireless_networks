地址域：多个站共用一条链路时区分“是谁”

NRM 的规则

地址域总是从站的地址：主站 → 从站，写接收的从站的地址（点名）；从站 → 主站，写发送的从站自己的地址（报名）。主站自己没有地址，因为它是唯一的。

例

主站 A，三个从站，地址 1、2、3。A → B2：地址 = 2；B2 → A：地址 = 2；B3 → A：地址 = 3。每个从站只处理地址是自己的帧，其余的忽略。

广播

地址全 1（8 位都是 1）表示“所有站”，所有从站都接收。

点到点

对方只有一个，地址域没有实际作用（PPP 里固定填 FF）；平衡模式里它用来区分“命令”和“响应”。

【2 分钟】 地址域：多个站共用一条链路时区分“是谁”。NRM（主从式）中的规则：地址域总是从站的地址。主站到从站，写接收的从站的地址（点名）；从站到主站，写发送的从站自己的地址（报名）；主站自己没有地址，因为它是唯一的。例：主站 A，三个从站，地址 1、2、3。A → B2：地址 2；B2 → A：地址 2；B3 → A：地址 3。每个从站只处理地址是自己的帧，其余的忽略。 点到点链路：对方只有一个，地址域没有实际作用（PPP 里固定填 FF）。平衡模式里它用来区分“命令”和“响应”。广播地址：全 1（8 位都是 1）表示所有站，所有从站都接收。
