发送方 A

接收方 B

I(1,2)

RR(2)

RR(3)

I(0,1)：SN = 0，RN = 1

I(2,1)：SN = 2，RN = 1

B 发的 I(0,1)：SN = 0，是 B 的第 0 号数据；RN = 1，顺便告诉 A：你的 0 号我收到了。A 发的 I(2,1)：SN = 2；RN = 1：已收到 B 的 0 号，期望 1 号。最后各发一个 RR，补上最后的确认。中间没有一个单独的确认帧。

确认都搭了数据帧的便车，链路用得更充分。

【3 分钟】 全双工：双方同时发数据，确认“顺路”带着。看 B 发的 I(0,1)：SN = 0，这是 B 的第 0 号数据；RN = 1，顺便告诉 A，你的 0 号我收到了。看 B 的 I(1,2)：SN = 1，RN = 2，已收到 A 的 0、1。看 A 发的 I(2,1)：SN = 2，A 的第 2 号数据；RN = 1，已收到 B 的 0 号，期望 1 号。最后各发一个 RR：双方都没有新数据要发了，就用 RR 补上最后的确认：A 的 RR(2) 确认 B 的 0、1，B 的 RR(3) 确认 A 的 0 到 2。 中间没有一个单独的确认帧：确认都搭了数据帧的便车，链路用得更充分。
