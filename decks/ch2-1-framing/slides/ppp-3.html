【3 分钟】 用一次宽带拨号来看“协议类型”字段怎么起作用。你在家里的路由器或电脑上输入宽带账号和密码，点“连接”，这条 PPP 链路上依次发生： 1. 建立链路：双方用 LCP（链路控制协议）的帧协商参数，比如最大帧长、用哪种认证方式。这些帧的“协议”字段是 C021。 2. 身份认证：验证账号和密码，用 PAP 或 CHAP，协议字段分别是 C023 或 C223。 3. 配置网络层：NCP（网络控制协议）的帧为你分配 IP 地址。对 IP 来说，协议字段是 8021。 4. 传输数据：之后的帧，载荷都是 IP 数据报，协议字段是 0021。这时你浏览网页、看视频，每个 IP 数据报都被装进这样的帧里。 下面的结构图：不管哪一步，帧的结构都是一样的：7E FF 03，协议 2 字节，信息，FCS，7E，只有“协议”字段的值和信息的内容不同。接收方看到“协议”字段，就知道交给谁处理。 所以 PPP 之所以比 SLIP 强，不只是组帧，而是它在组帧的基础上，把“拨号上网的整个过程”也标准化了。 [提示：这一页的重点是“协议类型字段的作用”，不要陷入 LCP/NCP 的细节。]
