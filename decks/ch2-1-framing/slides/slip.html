SLIP：两个特殊字节，两条规则

路标 END

C0

帧的起点和终点：一帧 = C0 + IP 数据报 + C0

转义字符 ESC

DB

载荷里碰到 C0 或 DB 时，用它来改写

发送方

C0 → DB DC

DB → DB DD；其他字节原样

接收方

反过来还原

DB DC → C0，DB DD → DB；见到 C0 就是边界

SLIP（串行线路 IP，RFC 1055，1988 年）：早年用电话线和调制解调器拨号上网时，把 IP 数据报装进帧里发出去。

线路上的 C0 只会是路标：载荷里的 C0 被改写成 DB DC，接收方见到 C0 就一定是边界。

【3 分钟】 真实协议一：SLIP，串行线路 IP。它是早年用电话线和调制解调器拨号上网的数据链路协议（RFC 1055，1988 年），只负责一件事：把 IP 数据报装进帧里发出去。 和玩具协议对应：路标 ~ 对应字节 END = C0；转义字符 \ 对应字节 ESC = DB。帧格式：END + IP 数据报 + END。转义规则两条：载荷里的 C0 变成 DB DC；载荷里的 DB 变成 DB DD；其他字节原样。接收方反过来：见到 DB DC 还原成 C0，见到 DB DD 还原成 DB，见到 C0 就是帧边界。 一个巧妙的设计：线路上的 C0 只会是路标。载荷里的 C0 被改写成 DB DC，所以帧的中间根本不会出现 C0。接收方只要见到 C0，就一定是边界，不需要记住“前一个字节是不是转义字符”。
