【3 分钟 · 进阶】 把 Flag 一般化：一个 0 加 j 个 1，共 j+1 位。HDLC 取 j = 6。对应的插入规则是：数据里每出现连续 j−1 个 1，就插一个 0（HDLC 里 j−1 = 5）。 插入的 0 有多少？“0 后面连续 j−1 个 1”共 j 位，出现的概率是 1/2^j。平均插入个数大约是 k/2^j。（j = 6 时就是上一页的 k/64。） 总开销 = 插入的 0 + Flag 本身，也就是 OV(j) ≈ k/2^j + (j+1)。 第一项：j 越大，数据里越不容易撞上 Flag，插入的越少。第二项：j 越大，Flag 本身越长。一增一减，所以总开销一定在某个 j 处最小。 例：HDLC，j = 6，k = 1000，OV = 1000/64 + 7 ≈ 15.6 + 7 = 22.6 位，占 1000 位的 2.3%。 下一页画图，看看这个最小值在哪里。 [备注：精确公式是 OV(j) = (k − j + 3)/2^j + j + 1，当 k 远大于 j 时，和上面的近似式相差很小。] [约定：真实的 HDLC Flag 是 8 位（01111110）。这里按教材的约定，把帧尾记为 0 后面 j 个 1，共 j + 1 位，帧尾之后的那个 0 与下一帧的开头共用；所以 j = 6 时 Flag 记 7 位。]
