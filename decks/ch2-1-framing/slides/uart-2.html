接收方怎么读

看到下降沿后，每隔 1 个位时间在中点读一次。

【3 分钟】 具体走一个例子：发送字母 “A”。 第一步，查表：A 的 ASCII 码是十六进制 41，上一页学过，41 = 0100 0001。 第二步，串口规定先发最低位。0100 0001 倒过来读：最低位是 1，然后 0 0 0 0 0，再 1，最高位 0。所以 D0 到 D7 依次是 1 0 0 0 0 0 1 0。 第三步，加路标：前面加起始位 0，后面加停止位 1。线路上的电平如图：先是空闲时的高电平，起始位让线路掉下来（橙色那一条下降沿），然后是 8 位数据，最后停止位让线路回到高电平。 两个数字：每个字符要发 10 位，有效的只有 8 位，效率是 80%。如果速率是 9600 波特（每秒 9600 位），则每秒能传 9600 ÷ 10 = 960 个字符。 接收方怎么读？它检测到那条下降沿后，每隔一个位时间（1/9600 秒）在位的中点采样一次，一共 8 次，再采样到停止位 1。所以收发双方只要事先约定好同样的速率（波特率），就不需要共享时钟——这就是“异步”。每个字符都重新对齐一次，时钟误差累积不起来。 [提示：这个例子的缺点是什么？每 8 位就要多发 2 位，比较浪费。能不能不要每个字符都加路标，只在一整块数据的前后加？——这正是下面要讲的。]
