【4 分钟 · 推导请带着学生走一遍】 我们来算令牌桶里的分组要等多久。用参考课件的模型：时隙系统，一个时隙是令牌产生的间隔 1/r。每个时隙里，k 个分组到达的概率 a_k 服从泊松分布，参数 ρ 是到达率除以令牌速率。 状态：i = W + P − B。W 是桶的容量，P 是在等令牌的分组数，B 是桶里的令牌数。i = 0：桶是满的，没有分组在等；0 到 W 之间：没有分组在等，桶里有 W − i 个令牌；大于 W：桶是空的，有 i − W 个分组在等令牌。 状态在时隙结束的时刻变化，而且在令牌到达以后。k 个分组到达，每个要么拿走一个令牌，要么排队，i 增加 k；然后新产生一个令牌，要么放进桶里，要么给等着的分组，i 减 1；但桶满的时候令牌被丢弃，i 不能再小于 0。所以 i' = max(i + k − 1, 0)。转移概率：从 0 到 i 是 a_{i+1}，从 0 到 0 是 a_0 + a_1，从 j 到 i 是 a_{i−j+1}。 稳态时，令牌的平均使用速率等于分组的到达速率：(1 − p_0 a_0) r = λ，所以 p_0 a_0 = 1 − ρ。这个模型其实就是一个离散时间的 M/D/1 队列：每个时隙最多服务 1 个。
