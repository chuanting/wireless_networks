练习（二）：码分、时延与利用率

④

码 c1 = (+1, +1, +1, +1)，c2 = (+1, −1, +1, −1)。用户 1 发 −1，用户 2 发 +1。求信道上叠加的信号，并分别解码。

⑤

m = 5，总到达率 λ = 0.4（个 / 时间单位）。求 FDM、TDM 与理想总队列的平均时延。

⑥

20 个用户做 TDMA，每个用户平均只有 5% 的时间有数据。信道利用率是多少？你能想到什么办法提高？

【4 分钟 · 参考答案】 ④ 用户 1 发 −c1 = (−1, −1, −1, −1)，用户 2 发 +c2 = (+1, −1, +1, −1)，叠加 = (0, -2, 0, -2)，即 (0, −2, 0, −2)。用 c1 解码：(0 − 2 + 0 − 2) ÷ 4 = −1；用 c2 解码：(0 + 2 + 0 + 2) ÷ 4 = +1。 ⑤ FDM：T = 5 + 0.4×5/(2×0.6) = 5 + 1.667 = 6.67；TDM：T = 1 + 2.5 + 1.667 = 5.17；理想总队列：T = 1 + 0.4/(2×0.6) = 1.33（单位：全速发完一个分组的时间）。 ⑥ 利用率是 5%，其余 95% 的时隙空着（每个时隙的占用概率都是 5%，不应该再乘用户数）。办法：不要给每个用户固定的时隙，改成“谁有数据谁用”：随机接入或预约，这就是后面几节的内容。 [验算：⑤ 用事件模拟核对过（m = 5，λ = 0.4：6.67、5.17、1.33）。]
