0 = 空闲，没人发；1 = 成功，恰好一人发；e = 碰撞，两人以上同时发。

④ 到达：泊松过程

每个节点的分组按泊松过程独立到达，总到达率 λ（分组/时隙）。

例：λ = 0.3，平均每 3.3 个时隙来 1 个新分组。

用泊松，是因为大量独立用户叠加后近似泊松（1.2），而且“无记忆”，好算。

有了 0 / 1 / e 的反馈，节点就能据此决定：要不要重发？等多久？

【3 分钟】 接着约定另外两件事：反馈和到达。 第三，反馈。节点要决定怎么办，必须知道信道上发生了什么。我们假设每个时隙结束时，所有节点都能立刻知道这个时隙的结果，只有三种：0，空闲，没有人发；1，成功，恰好有一个节点发，传输成功；e，碰撞，有两个或两个以上的节点同时发。 看图里的八个时隙：时隙 1，没人发，反馈 0；时隙 2，A 一个人发，反馈 1，成功；时隙 3，A 和 B 同时发，反馈 e，碰撞；时隙 4，又空闲；时隙 5，C 单独发，成功；时隙 6，B 和 C 撞了；时隙 7，A 成功；时隙 8，D 成功。八个时隙里，成功 4 次，碰撞 2 次，空闲 2 次。 第四，到达。我们假设每个节点的分组按泊松过程独立到达，总到达率是 λ，单位是分组每时隙。比如 λ 等于 0.3，就是平均每 3.3 个时隙来一个新分组。为什么用泊松？大量独立用户叠加起来近似泊松，我们在 1.2 节学过；它还有无记忆性，数学上好算。 [提示：时隙 3 里“A B”，说明 A 和 B 正好同时有分组要发，这样的“同时”在随机接入里是常态。]
