第一部分 · 分类

多址协议的三大类

固定分配

做法

用户一接入，就分到一份资源（频率、时隙、码、空间），独享到通信结束。

类比

开会：每人固定发言一段时间。

典型协议

FDMA、TDMA、CDMA、SDMA

优点 / 缺点

无碰撞、公平 / 没数据时浪费

随机接入

做法

想发就发（或先听一听），撞了再重发；靠竞争获得信道。

类比

讨论会：谁想说谁说，撞了就让一让。

典型协议

ALOHA、CSMA、CSMA/CD、CSMA/CA

优点 / 缺点

灵活、轻载很快 / 重载时碰撞多

预约

做法

发数据前先预约资源，预约到了才发，数据传输无碰撞。

类比

先举手报名，主持人安排顺序。

典型协议

PRMA（分组预约多址）等

优点 / 缺点

兼顾效率与无碰撞 / 预约本身要花开销

今天讲固定分配；4.2 到 4.4 讲随机接入；预约类在课程后面的专题里涉及。

【3 分钟】 把多址协议分类，有三大类。 第一类，固定分配，也叫无竞争或静态分配：用户一接入信道，就专门给他分一份资源，可能是频率、时隙、码字或者空间，他独享这份资源，直到通信结束。典型的有 FDMA、TDMA、CDMA 和 SDMA。优点是没有碰撞，公平，时延有保证；缺点是用户没数据时，资源白白浪费。 第二类，随机接入：用户可以随时接入信道，可能并不顾及别人有没有在发。多个用户同时发就会冲突，所以关键问题是：怎样解决冲突，让所有碰撞的用户最终都能成功。典型的有 ALOHA、CSMA、带碰撞检测的 CSMA/CD，以及带碰撞避免的 CSMA/CA。优点是灵活，轻载时很快；缺点是重载时碰撞多，吞吐量下降。 第三类，预约：在传数据之前，先预约资源，预约到了之后，在这段资源里就没有冲突了。比如 PRMA。优点是兼顾了效率和无碰撞；代价是预约本身要花开销，预约请求自己也可能碰撞。 这一讲讲固定分配。4.2 到 4.4 讲随机接入。 [参考课件的分类图里，固定分配列了 TDMA、FDMA、CDMA 等，随机接入列了 ALOHA、CSMA 等，预约接入列了 PRMA。]
