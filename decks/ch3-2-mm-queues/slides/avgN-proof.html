求和范围：n 从 0 到无穷。等比级数可收敛的前提是 0 ≤ ρ < 1。

【拓展3分钟】 先回顾S=sum rho^n=1/(1-rho)，其中n=0到无穷，rho小于1。两边求导，左边sum n rho^(n-1)，右边1/(1-rho)^2；再乘rho，得到sum n rho^n=rho/(1-rho)^2。 代入N=(1-rho)sum n rho^n，约去一项得到N=rho/(1-rho)。在rho严格小于1的收敛范围内可逐项求导。 本页是给想补齐代数过程的同学，不把级数求导作为理解排队系统的前提。
