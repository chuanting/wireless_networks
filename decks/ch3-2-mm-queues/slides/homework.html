六道小题，检验一下

① M/M/1 基本量

λ = 3，μ = 4（个/秒）。求 p0、N、NQ、T、W，以及 P(N ≥ 5)。

② 链路规划

链路 1 Mb/s，平均分组 1000 位（M/M/1）。要求平均时延 ≤ 10 ms，λ 最大是多少？平均分组变为 2000 位呢？

③ 统计复用

5 个业务，每个 λ = 20，μ = 50（个/秒）。各用一条信道与合并成一条（λ = 100，μ = 250），时延各是多少？

④ 有限缓冲

M/M/1/K：ρ = 0.5，K = 4。求丢包概率。

⑤ 爱尔兰 C

m = 2，λ = 1.6，μ = 1。求 a、ρ、等待概率 PQ、W、T。

⑥ 爱尔兰 B

交换机有 5 条中继线，呼叫业务量 a = 2 爱尔兰。用递推求阻塞概率；至少加到几条线路才能使阻塞 ≤ 1%？

【0.5 分钟 · 参考答案，课上不必讲】 ① ρ = 3/4 = 0.75。p_0 = 1 − ρ = 0.25；N = ρ/(1−ρ) = 3；N_Q = ρ^2/(1−ρ) = 0.5625/0.25 = 2.25；T = 1/(μ−λ) = 1 秒；W = T − 1/μ = 0.75 秒；P(N ≥ 5) = ρ^5 = 0.2373。 ② μ = 1 000 000 / 1000 = 1000 个/秒。T = 1/(μ−λ) ≤ 0.01 → μ − λ ≥ 100 → λ ≤ 900 个/秒（ρ ≤ 0.9）。平均分组 2000 位：μ = 500，λ ≤ 400 个/秒。 ③ 各用一条：T = 1/(50−20) = 33.3 ms。合并：T = 1/(250−100) = 6.67 ms，是原来的 1/5。 ④ P_丢 = (1−ρ)ρ^K/(1−ρ^(K+1)) = 0.5 × 0.0625 / (1 − 0.03125) = 0.03125/0.96875 ≈ 3.23%。 ⑤ a = 1.6，ρ = a/m = 0.8。爱尔兰 C：P_Q = 71.1%（用 C = B/(1−ρ(1−B))，B(2, 1.6) = 0.2,… 或直接：p_0 = [1 + 1.6 + 1.6^2/(2×0.2)]^−1 = 1/(1 + 1.6 + 6.4) = 1/9，P_Q = p_0 × 6.4 = 0.711）。W = P_Q/(mμ−λ) = 0.711/0.4 = 1.78；T = 1.78 + 1 = 2.78。 ⑥ B(1) = 2/3 = 0.667；B(2) = 0.4；B(3) = 0.2105；B(4) = 0.0952；B(5) = 0.0367：阻塞概率约 3.67%。B(6) = 0.0121（仍 > 1%）；B(7) = 0.0034。所以至少 7 条。 [验算：⑤ p_0 = 1/9 = 0.111；a^m/(m!(1−ρ)) = 2.56/(2×0.2) = 6.4；0.711/0.4 = 1.778。④ 0.03125/0.96875 = 0.03226。]
