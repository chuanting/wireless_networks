④

M/M/1/K：λ = μ，K = 4。求丢包概率、有效到达率和平均人数；被接纳者的平均时延是多少？

⑤

M/M/2：λ = 1.6，μ = 1（个/min）。求 a、ρ、等待概率、平均等待和时延。

⑥

业务量 a = 4 爱尔兰。用递推求 5 条线路时的阻塞概率；至少要几条线路，阻塞才不超过 1%？

【3 分钟 · 参考答案】 ④ ρ = 1 时每个状态概率相同，p_n = 1/5。丢包概率 B = 0.2；有效到达率 λ(1−B) = 0.8λ；平均人数 N = (0+1+2+3+4)/5 = 2；被接纳者的时延 T = N/(0.8λ) = 2.5/λ，λ = μ 时就是 2.5/μ。 ⑤ a = λ/μ = 1.6，ρ = a/m = 0.8。p_0 = [1 + 1.6 + 1.6^2/(2×0.2)]^−1 = 1/(1 + 1.6 + 6.4) = 1/9；等待概率 P_Q = p_0 × a^m/[m!(1−ρ)] = (1/9) × 6.4 = 0.711；W = P_Q/(mμ−λ) = 0.711/0.4 = 1.78 分钟；T = W + 1/μ = 2.78 分钟。 ⑥ B(1) = 0.8，B(2) = 0.615，B(3) = 0.451，B(4) = 0.311，B(5) = 0.199：5 条线路阻塞约 19.9%。继续：B(9) = 1.33%（仍大于 1%），B(10) = 0.53%。所以至少需要 10 条线路。 [验算：⑤ 6.4/9 = 0.7111，/0.4 = 1.778；⑥ B(m,4) 递推，B(9) = 0.0133，B(10) = 0.0053。]
