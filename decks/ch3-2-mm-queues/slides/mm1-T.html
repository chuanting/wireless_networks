第一部分 · M/M/1

时延 T = 1 / (μ − λ)

用 Little 定理变成时延

平均时延：T = N / λ = ρ / [λ(1 − ρ)] = 1 / (μ − λ)

平均等待：W = T − 1/μ = ρ / (μ − λ)

队列里的平均人数：NQ = λW = ρ 的平方 ÷ (1 − ρ)

到达时需要等待的概率：P(等待) = 1 − p0 = ρ

最后一条：泊松到达“看到”的是时间平均（PASTA 性质），所以顾客来时发现服务员忙的概率，等于服务员忙的时间比例 ρ。

核对 3.1 的曲线

μT = 1 / (1 − ρ)：ρ = 0.5 → 2；0.9 → 10；0.99 → 100。就是“曲棍球棒”！

直觉：剩余容量

μ − λ 是服务员“多出来的服务能力”。多出来越少，等得越久。

T = 1/(μ − λ)：M/M/1 里最重要的一个公式。

【4 分钟 · 重点】 把 N 变成时延，一步：Little 定理。T 等于 N 除以 λ。N 是 ρ 除以 (1 减 ρ)，ρ 是 λ 除以 μ，代进去化简：T 等于 1 除以 (μ 减 λ)。这就是 M/M/1 最重要的公式。 再看其他量。平均等待时间 W：停留减去服务，T 减 1/μ，等于 ρ 除以 (μ 减 λ)。队列里的平均人数 N_Q：等待时间乘 λ，等于 ρ 的平方除以 (1 减 ρ)。到达时需要等待的概率：系统非空的概率，1 减 p_0，等于 ρ。 最后一条有一个微妙之处：顾客到达的时刻，看到的系统状态，和系统在任意时刻的平均状态是一样的吗？对泊松到达，是的——这叫 PASTA 性质，“泊松到达看到的是时间平均”。所以顾客到达时，服务员忙的概率就是服务员忙的时间比例，ρ。对其他到达过程，这一条不一定成立。 右边两点。一，核对 3.1 的曲线：μ 乘 T 等于 1 除以 (1 减 ρ)，ρ 等于 0.5 时是 2，0.9 时是 10，0.99 时是 100。这就是 3.1 节那条“曲棍球棒”曲线的公式！二，直觉：μ 减 λ，是服务员“多出来的服务能力”，多出来越少，等得越久。 [验算：N_Q = λW：ρ=0.8 时，ρ^2/(1−ρ) = 3.2；W = ρ/(μ−λ)。]
