来一个：人数 n → n + 1，到达速率 λ。

完成一个：人数 n → n − 1。只有一个服务员，所以非空时离开速率始终是 μ。

系统空着时没人可离开；人数多，并不代表同时有更多人在服务。

【3分钟】 圆圈不是服务员或具体顾客，而是“整个系统内有几个人”的状态。状态3是两个在等、一个在服务，来一个变4，完成一个变2。 问：有3个人时离开速率是3mu吗？不是，只有一个人正在接受服务，其余在等。只要非空，完成的速率都是mu；空系统则是0。 把一段很短时间记delta，来一个的概率近似lambda×delta；非空时完成一个近似mu×delta；极短时间内发生多件事的概率更小。主课只需理解箭头的方向和速率。指数无记忆性保证不用记录已服务时长；到达过程也不记过去。 人数随时间记N(t)。这类只在相邻整数间跳的随机过程叫生灭过程，出生表示到达、死亡表示完成，不需要先修马尔可夫链课程。
