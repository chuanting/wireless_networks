来一个：很短的时间 δ 内，概率约 λδ（泊松）：n → n + 1。

走一个：概率约 μδ（指数无记忆）：n → n − 1。状态 0 没人可走。

同时两件事：概率是 δ 的高阶小量，忽略。

人数 N(t) 是一条生灭链：往上跳速率 λ，往下跳速率 μ。

【3 分钟 · 重点】 描述一个排队系统的状态，最自然的是：系统里现在有几个顾客，记作 N(t)。图里的圆圈就是状态 0、1、2…… 这个状态怎样变化？看一段很短的时间 δ。第一，可能来一个新顾客，概率约是 λ 乘 δ，这是泊松过程的性质。第二，如果系统里有人，可能服务完一个顾客离开，概率约是 μ 乘 δ：这里用到了指数分布的无记忆性，不管他已经服务了多久，接下来 δ 时间内服务完的概率都是 μδ。所以只需要知道系统里有几个顾客，不需要知道服务了多久。第三，两件事同时发生的概率是 δ 的高阶小量，可以忽略。 所以状态只会往上跳一格，速率 λ；或者往下跳一格，速率 μ。状态 0 例外：没人，就没有离开，只有向上的箭头。 这样只在相邻状态之间跳的链叫生灭链，第 1.2 节学过。上面的蓝色箭头是“出生”，下面的黑色箭头是“死亡”。
