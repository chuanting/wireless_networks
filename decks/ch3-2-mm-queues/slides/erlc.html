爱尔兰 C 公式：这个等待概率叫爱尔兰 C 公式：到达的顾客发现 m 个服务员全忙的概率。

m = 1：等待概率就是 ρ：公式回到 M/M/1。

记号：“C”只是这个公式的名字，不是链路速率 C。

泊松到达看到时间平均：到达时全忙的概率，就是状态 n ≥ m 的概率。

【5 分钟 · 重点】 方法和 M/M/1 一样：切一刀。在 n 和 n+1 之间切一刀：向右是 λ 乘 p_n；向左，是 n+1 状态的概率乘上这时的离开速率：n+1 个顾客时，如果 n+1 不超过 m，离开速率是 (n+1)μ；如果超过了，是 mμ。 所以当 n 小于 m 时：(n+1) p_{n+1} 等于 a 乘 p_n，一层层推下去，p_n 等于 p_0 乘 a 的 n 次方除以 n 的阶乘。当 n 大于等于 m：p_{n+1} 等于 ρ 乘 p_n，从 p_m 开始每往后一格乘 ρ，所以 p_n 等于 p_0 乘 a 的 n 次方，除以 m 的阶乘和 m 的 (n 减 m) 次方。p_0 由概率之和为 1 求出：1 除以 p_0 等于 n 从 0 到 m−1 的 a^n/n! 之和，加 a^m/[m!(1−ρ)]。 最重要的一个量：到达的顾客发现 m 个服务员全忙、需要等待的概率，等于 n 大于等于 m 的所有 p_n 之和。后半部分是等比级数，求和得 P_Q 等于 p_0 乘 a 的 m 次方，除以 m 的阶乘乘 (1 减 ρ)。这个公式叫爱尔兰 C 公式，是客服中心、排队论里最常用的公式。 讲课时可以把它叫“等待概率”，避免和上一讲的链路速率 C 混淆。m 等于 1 时，P_Q 就是 ρ，所有公式退化为 M/M/1。
