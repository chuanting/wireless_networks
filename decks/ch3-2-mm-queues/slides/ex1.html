练习（一）：M/M/1 及其应用

①

λ = 3，μ = 4（个/s）。求空闲概率、平均人数、队列里的平均人数、时延、等待时间，以及系统里至少有 5 个顾客的概率。

②

链路 2 Mb/s，平均分组 2000 位（M/M/1）。要求平均时延 ≤ 5 ms，λ 最大是多少？

③

5 个业务各自 λ = 20、μ = 50（个/s）。各用一条信道，与合并成一条（λ = 100，μ = 250），时延各是多少？

【3 分钟 · 参考答案】 ① ρ = 3/4 = 0.75。空闲概率 p_0 = 1 − ρ = 0.25；N = ρ/(1−ρ) = 3；N_Q = ρ^2/(1−ρ) = 0.5625/0.25 = 2.25；T = 1/(μ−λ) = 1 秒；W = T − 1/μ = 0.75 秒；至少 5 个顾客的概率 ρ^5 = 0.2373。 ② μ = 2×10^6 / 2000 = 1000 个/秒。T = 1/(μ−λ) ≤ 0.005 → μ − λ ≥ 200 → λ ≤ 800 个/秒（ρ ≤ 0.8）。 ③ 各用一条：T = 1/(50−20) = 33.3 ms。合并：T = 1/(250−100) = 6.67 ms，是原来的 1/5。 [验算：0.75^5 = 0.2373；1/30 = 0.0333；1/150 = 0.00667。]
