练习：先解释，再计算

①

系统里现在有 3 个顾客，几个人在等、几个人在服务？λ = 4、μ = 5（个/s），是否表示每秒实际离开 5 个？

②

仍取 λ = 4、μ = 5（个/s）。求负荷、空闲概率、平均停留时间和平均等待时间；再用 Little 定理求两种平均人数。

③

保持 μ = 5 个/s，把 λ 提高到 4.5 个/s，平均停留时间变成多少？若 λ = 5 个/s，还能使用稳态公式吗？

每个答案都要说清：数的是谁、包含什么、单位是什么。

【课堂练习 · 参考答案】 ① 系统内 3 个顾客：1 个正在服务，2 个在等待。μ 是服务员忙时的处理能力；没有顾客时服务员会空闲，因此不能把 μ 当成整个系统的实际离开率。无丢失且稳定时，长期实际离开率等于到达率 4 个/s。 ② ρ = 4/5 = 0.8，空闲概率 p_0 = 0.2。平均停留时间 T = 1/(5−4) = 1 s；平均服务时间 1/μ = 0.2 s，所以平均等待时间 W = 1−0.2 = 0.8 s。Little 定理用于整个系统：N = λT = 4×1 = 4 个；用于等待区：N_Q = λW = 4×0.8 = 3.2 个。平均人数可以是小数，它是长期平均，不是某次看到的实际人数。W 对所有到达者平均，包括不用等的人。 ③ λ = 4.5 时 ρ = 0.9，T = 1/(5−4.5) = 2 s，W = 1.8 s。流量只增加 12.5%，平均停留时间翻倍。λ = μ = 5 时，不满足 ρ < 1，没有可用于这里的稳态概率分布和有限稳态平均时延；不能把公式分母为 0 当作一个可计算的秒数，也不能说平均来得一样快就一定不排队。 [教学提示：先让学生说边界，再算数。若只会代入公式，回到单个顾客的时间线与状态 3 的实物示意。]
