自己动手：用程序验证排队公式

基础

M/M/1：模拟与公式对照

用事件模拟产生 40 万个顾客（λ = 0.8，μ = 1）。统计系统里有 n 个顾客的时间比例，与 (1 − ρ) ρ 的 n 次方对比；再比较 T 与 1/(μ − λ)。

检验：p0 应约 0.2；T 应约 5（模拟约 4.9）。

中级

M/M/m：慢信道 vs 快信道

实现 M/M/4（共用队列）和 M/M/1（4 倍速），在 ρ = 0.1、0.5、0.9 下比较平均时延。

检验：T 之比应接近 3.6、2.2、1.19；与爱尔兰 C 公式对照。

进阶

爱尔兰 B 计算器与模拟

写一个爱尔兰 B 递推函数；再模拟损失制系统，验证 B(3, 2) 与 B(10, 8)；并画出“1% 阻塞下，线路数 vs 利用率”曲线。

检验：B(3, 2) ≈ 0.2105；B(10, 8) ≈ 0.1217；利用率随 m 增大而上升。

想挑战更多？把服务时间换成固定长度，看平均等待怎样变化（这正是 3.3 节 P-K 公式要回答的）。
