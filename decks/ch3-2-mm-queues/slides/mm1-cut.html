切一刀（在 n 与 n + 1 之间）

稳态时，每秒钟越过这一刀向右的平均次数 = 向左的平均次数。

向右：在 n 状态（概率 pn），以速率 λ 跳上去：λ pn。

向左：在 n + 1 状态，以速率 μ 跳下来：μ p(n + 1)。

得到递推

λ pn = μ p(n + 1)

即 p(n + 1) = ρ pn，其中 ρ = λ / μ。

递推下去：pn = ρ 的 n 次方 × p0。

【4 分钟 · 重点】 现在来解稳态分布：系统处在“有 n 个顾客”这个状态的概率，记作 p_n。 用“切一刀”：在 n 和 n+1 之间画一条竖直的虚线。稳态的时候，系统不可能一直往一个方向漏，所以每秒钟越过这一刀向右的平均次数，等于向左的平均次数。 向右：系统要处在状态 n，概率 p_n，然后以速率 λ 来一个顾客，跳到 n+1，所以每秒向右越过的平均次数是 λ 乘 p_n。 向左：系统处在状态 n+1，概率 p_{n+1}，然后以速率 μ 服务完一个顾客，跳回 n，所以是 μ 乘 p_{n+1}。 两者相等：λ p_n 等于 μ p_{n+1}。 整理成 p_{n+1} 等于 ρ 乘 p_n，其中 ρ 是 λ 除以 μ。一层一层往下推：p_1 等于 ρ p_0；p_2 等于 ρ 的平方乘 p_0；一般地，p_n 等于 ρ 的 n 次方，乘上 p_0。 还剩一个未知数 p_0，下一页用“概率之和等于 1”来定它。 [提示：也可以用“全局平衡方程”逐个状态写，结果完全一样，但切一刀要简单得多——1.2 节讲过。]
