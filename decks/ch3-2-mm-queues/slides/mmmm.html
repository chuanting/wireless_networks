第二部分 · M/M/m/m

损失制与爱尔兰 B 公式

M/M/m/m：m 条线路，没有等待位置（损失制）

到达时若 m 条线路全忙，呼叫立刻被拒绝（阻塞）。状态只有 0, 1, …, m。

切一刀和 M/M/∞ 完全一样，只是只取到 m 为止：

pn = (a 的 n 次方 / n!) / Σ(k=0…m) (a 的 k 次方 / k!)

阻塞概率 = 所有线路全忙的概率（泊松到达看到时间平均）：

B(m, a) = (a 的 m 次方 / m!) / Σ(k=0…m) (a 的 k 次方 / k!)

——爱尔兰 B 公式。

小例子：m = 3，a = 2

各项 a 的 k 次方 / k!：1, 2, 2, 1.33；和 = 6.33。

阻塞概率

B = 1.33 / 6.33 ≈ 21%：每 5 个呼叫被拒绝 1 个。

对照 3.1 节

300 线、a = 360：下限 16.7%，精确 17.9%；a = 300：下限 0，精确 4.5%。

惊人的性质

公式对任意服务时间分布都成立，只要平均值是 1/μ（不敏感性）。

【4 分钟 · 重点】 M/M/m/m：m 个服务员，系统里最多 m 个顾客，没有等待的位置。来的顾客，如果发现 m 个服务员全忙，就立刻被拒绝，走掉了。这是电话网的模型：m 条线路，全忙就打不通——叫损失制，被拒绝的概率，叫阻塞概率或者呼损率。 分析方法和 M/M/∞ 完全一样，只是状态只有 0 到 m。切一刀得到：p_n 正比于 a 的 n 次方除以 n 的阶乘。归一化：除以 k 从 0 到 m 的所有项之和。 阻塞概率，就是 m 条线路全忙的概率 p_m：B(m, a) 等于 a 的 m 次方除以 m 的阶乘，再除以所有项的和。这就是爱尔兰 B 公式，电话网用了一百多年。 一个小例子：m 等于 3，a 等于 2。各项是 1、2、2、1.33，和是 6.33。阻塞概率 1.33 除以 6.33，约 21%：每 5 个呼叫被拒绝 1 个。 对照 3.1 节的例子：300 条线路，a 等于 360，Little 定理给的下限是 16.7%，精确值是 17.9%，很接近；a 等于 300，下限是 0，精确值 4.5%——随机性造成的。 还有一个惊人的性质：这个公式不仅适用于指数分布的通话时间，对任意的服务时间分布都成立，只要平均值是 1/μ。这叫“不敏感性”，所以电话网设计起来特别方便。 [验算：B(3,2) = 0.2105；B(300,360) = 0.1786；B(300,300) = 0.0447；模拟验证过 B(3,2) ≈ 0.210，B(10,8) ≈ 0.121。]
