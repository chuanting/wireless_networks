状态 = 系统里的顾客数 N(t)

在很短的时间 δ 内：

来 1 个顾客：概率 ≈ λδ（泊松）。

服务完 1 个（系统非空）：概率 ≈ μδ（指数，无记忆）。

两件事同时发生：概率是 δ 的高阶小量，忽略。

所以

状态只会 n → n + 1（到达，速率 λ）

或 n → n − 1（离开，速率 μ）。

状态 0 只有向上的箭头——没人可离开。

这是一条生灭链。

【3 分钟 · 重点】 描述一个排队系统的“状态”，最自然的是：系统里现在有几个顾客，记作 N(t)。图里的圆圈，就是状态 0、1、2、3…… 这个状态会怎样变化？看一段很短的时间 δ。第一，可能来一个新顾客，概率约是 λ 乘 δ——这是泊松过程的性质。第二，如果系统里有人，可能服务完一个顾客离开，概率约是 μ 乘 δ——这里用到了指数分布的无记忆性：不管他已经服务了多久，在接下来 δ 时间内服务完的概率都是 μδ。所以只需要知道系统里有几个顾客，不需要知道服务了多久。第三，两件事同时发生的概率，是 δ 的高阶小量，可以忽略。 所以状态只会往上跳一格，到达，速率 λ；或者往下跳一格，离开，速率 μ。状态 0 例外：系统里没人，就没有离开，只有向上的箭头。 这样的链，只在相邻状态之间跳，叫生灭链——第 1.2 节学过的。上面蓝色箭头是出生，下面橙色箭头是死亡。 下一页，用“切一刀”解出稳态分布。 [提示：强调“无记忆”这个关键：这是为什么 M/M 型系统好算。]
