数值：ρ = 0.5、0.8、0.9、0.95、0.99 时，N = 1、4、9、19、99。

【3 分钟】 有了 p_n，就可以求平均值了。平均顾客数 N 等于 n 乘 p_n 再求和，也就是 (1 减 ρ) 乘上 n 乘 ρ 的 n 次方求和。 这个求和有个小技巧：从等比级数出发，ρ 的 n 次方求和等于 1 除以 (1 减 ρ)；两边对 ρ 求导，右边变成 1 除以 (1 减 ρ) 的平方；再乘 ρ，得到：n 乘 ρ 的 n 次方求和，等于 ρ 除以 (1 减 ρ) 的平方。代回去，(1 减 ρ) 乘这个，约掉一个 (1 减 ρ)，得到 N 等于 ρ 除以 (1 减 ρ)。 右边的数值：ρ 等于 0.5，N 等于 1；0.8，N 等于 4；0.9，N 等于 9；0.95，19；0.99，99。ρ 越接近 1，N 增长越快，趋于无穷，和 3.1 的结论一致。下一页用 Little 定理把 N 变成时延。 [提示：数学基础薄弱的同学，记住结果 N = ρ/(1−ρ) 即可。求和可由 Σρ^n = 1/(1−ρ) 求导再乘 ρ 得到。]
