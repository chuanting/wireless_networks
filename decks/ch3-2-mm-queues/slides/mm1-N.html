平均顾客数 N = ρ / (1 − ρ)

平均顾客数 N

N = Σ n · pn = (1 − ρ) Σ n ρ 的 n 次方

求和的小技巧：已知 Σ ρ 的 n 次方 = 1/(1 − ρ)，两边对 ρ 求导，再乘 ρ：

Σ n ρ 的 n 次方 = ρ / (1 − ρ) 的平方

代入：

N = ρ / (1 − ρ)

趋势

ρ → 1 时，N → ∞：队列越来越长。

【3 分钟】 有了 p_n，就可以求平均值了。平均顾客数 N 等于 n 乘 p_n 再求和，也就是 (1 减 ρ) 乘上 n 乘 ρ 的 n 次方求和。 这个求和有个小技巧：从等比级数出发，ρ 的 n 次方求和等于 1 除以 (1 减 ρ)；两边对 ρ 求导，左边变成 n 乘 ρ 的 n 减 1 次方求和，右边是 1 除以 (1 减 ρ) 的平方；再两边乘 ρ，得到：n 乘 ρ 的 n 次方求和，等于 ρ 除以 (1 减 ρ) 的平方。代回去，(1 减 ρ) 乘这个，约掉一个 (1 减 ρ)，得到：N 等于 ρ 除以 (1 减 ρ)。 右边的表：ρ 等于 0.5，N 等于 1；ρ 等于 0.8，N 等于 4；ρ 等于 0.9，N 等于 9；ρ 等于 0.95，N 等于 19；ρ 等于 0.99，N 等于 99。ρ 越接近 1，N 增长越快，趋于无穷。 这个趋势，和上一节的曲线一致。下一页，用 Little 定理把 N 变成时延。 [提示：数学基础薄弱的同学，只要记住结果 N = ρ/(1−ρ) 即可，推导过程可课后看。]
