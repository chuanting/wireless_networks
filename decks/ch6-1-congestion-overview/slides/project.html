③

在 n = 2 到 10 的线形网络上，对长用户速率 x 从 0 扫到 1，画全网吞吐量，找最大点与公平点

n 对 (n + 1)/2

怎么检验：有效吞吐量应当先升后降；共享缓冲池在满负荷时几步之内死锁，分类后一次也不；最大点是 n，公平点是 (n + 1)/2。

改变假设：保持平均负荷不变，把泊松到达改成成批突发。比较超时比例、有效吞吐量和拐点位置。

同一个办法：先写一个能复现现象的小模拟器，再改参数。

【选做 · 课上只需 1 分钟介绍】 这页是给想动手的同学准备的，不在课上做。 基础：事件模拟一个有限缓冲区的 FIFO 队列，指数服务，泊松到达，发送方有超时；改变提供的负载，画有效吞吐量的曲线，应当先升后降。 中级：模拟四个节点的环，分共享缓冲池和按跳数分类的缓冲池，满负荷时数死锁的次数。 进阶：在 n 条链路的线形网络上，让长用户的速率 x 从 0 扫到 1，画全网吞吐量，找最大点和公平点。想挑战更多：改变超时和缓冲区大小，看拐点怎么移动。 改变假设：令每次到达带 1、4、10 个分组，按批大小同比减小批次到达率，使平均包率不变。保持服务率、缓冲区和超时门限不变，比较超时比例与有效吞吐量。报告多次随机运行的波动范围，判断原泊松模型的曲线能否代表突发输入。 [提示：这些练习不要求提交，愿意做的同学可以课后找老师交流。]
