【3 分钟】 为什么偏偏是减 1 和加 1.392？原则是：估计准确的时候，估计值的平均变化，要等于真实积压数的平均变化，这样估计才不会系统地跑偏。 估计准确时，G = 1。一个时隙的三种结局：空闲概率 1/e = 0.368，成功概率也是 0.368，碰撞概率 1 − 2/e = 0.264。真实的积压怎么变？每个时隙平均新来 λ 个；成功时走掉一个。所以去掉 +λ 以后，平均变化是 −0.368。估计怎么变？空闲减 1，成功减 1，碰撞加 c。去掉 +λ 以后平均变化是 −0.368 − 0.368 + c × 0.264。令它等于真实的 −0.368，得 c × 0.264 = 0.368，也就是 −1/e + c(1 − 2/e) = 0，解得 c = 1/(e − 2) ≈ 1.392。 怎么理解：成功的 −1，是因为真的走掉了一个分组；空闲的 −1 和碰撞的 +c 是“纠偏”：空闲说明发的人比估计的少，往下调；碰撞说明发的人比估计的多，往上调。估计准确时，这两种纠偏平均起来正好抵消：−0.368 + 1.392 × 0.264 = 0。 说明：这个平均平衡的计算解释了常数的来历，并不等于完整的贝叶斯推导，也不单独构成稳定性证明。 [验算：(1 − 2/e)/(e − 2) = 1/e，即 0.2642 × 1.3922 = 0.3679。用二项分布精确算，n = 30、q = 1/30 时，估计的平均变化 -0.368，真实的是 -0.374，已经很接近。]
