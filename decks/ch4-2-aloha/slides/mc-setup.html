精确一点：把积压数写成马尔可夫链

状态

n = 每个时隙开头的积压节点数，取 0, 1, …, m（有限 m 个节点，每个最多一个分组）。

两个概率

a：一个空闲节点在一个时隙里来新分组的概率，a = 1 − exp(−λ/m)；q：一个积压节点在一个时隙里重传的概率。

A(i, n) = C(m − n, i) a

i

 (1 − a)

m−n−i

m − n 个空闲节点里，恰有 i 个发新分组

R(j, n) = C(n, j) q

j

 (1 − q)

n−j

n 个积压节点里，恰有 j 个重传

例：m = 4，n = 2，a = 0.1，q = 0.3。A(0,2) = 0.81，A(1,2) = 0.18，A(2,2) = 0.01；R(0,2) = 0.49，R(1,2) = 0.42，R(2,2) = 0.09。

下一个时隙的积压数，只取决于现在的 n 和这个时隙里发生的事。

【3 分钟】 上一页的图是直观的，下面把它说精确。用有限模型：m 个节点，每个节点最多一个分组。 状态 n：每个时隙开头的积压节点数，取值 0 到 m。下一个时隙的 n 只取决于这个时隙的 n 和这个时隙里发生的事，所以 n 是一个马尔可夫链，1.2 节学过。 需要两个概率。a：一个空闲节点在一个时隙里来新分组的概率。每个节点的到达是速率 λ/m 的泊松过程，一个时隙里至少来一个的概率是 1 − e^(−λ/m)。q：一个积压节点在一个时隙里重传的概率，这是协议的参数。 于是有两个二项分布。A(i, n)：m − n 个空闲节点里，恰好有 i 个发新分组，等于组合数 C(m − n, i) 乘 a 的 i 次方，乘 (1 − a) 的 m − n − i 次方。R(j, n)：n 个积压节点里，恰好有 j 个重传，等于 C(n, j) 乘 q 的 j 次方，乘 (1 − q) 的 n − j 次方。 算一个例子：m = 4，n = 2，a = 0.1，q = 0.3。两个空闲节点：A(0,2) = 0.9^2 = 0.81；A(1,2) = 2 × 0.1 × 0.9 = 0.18；A(2,2) = 0.01。两个积压节点：R(0,2) = 0.7^2 = 0.49；R(1,2) = 2 × 0.3 × 0.7 = 0.42；R(2,2) = 0.09。下一页用它们写出转移概率。 [验算：程序对任意 m、n、a、q 检查，每一行转移概率之和等于 1。]
