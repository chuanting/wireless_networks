第三部分 · 马尔可夫链

精确一点：把积压数 n 写成马尔可夫链（假设 A）

状态

n = 每个时隙开头的积压节点数，取值 0, 1, …, m。

两个概率

a：一个空闲节点在一个时隙里来新分组的概率，a = 1 − exp(−λ/m)。

q：一个积压节点在一个时隙里重传的概率。

两个二项分布（C 是组合数）

m − n 个空闲节点里，恰有 i 个发新分组：

A(i, n) = C(m − n, i) · a

i

 (1 − a)

m − n − i

n 个积压节点里，恰有 i 个重传：

R(i, n) = C(n, i) · q

i

 (1 − q)

n − i

例：m = 4，n = 2，a = 0.1，q = 0.3。A(0, 2) = 0.81，A(1, 2) = 0.18，A(2, 2) = 0.01；R(0, 2) = 0.49，R(1, 2) = 0.42，R(2, 2) = 0.09。

【3 分钟】 上一页的图是直观的，下面把它说精确。用假设 A：m 个节点，每个节点最多一个分组。 状态 n：每个时隙开头的积压节点数，取值 0 到 m。下一个时隙的 n 只取决于这个时隙的 n 和这个时隙里发生的事，所以 n 是一个马尔可夫链，1.2 节学过。 需要两个概率。a：一个空闲节点在一个时隙里来新分组的概率。每个节点的到达是速率 λ/m 的泊松过程，一个时隙里至少来一个的概率是 1 减 e 的负 λ/m 次方。q：一个积压节点在一个时隙里重传的概率，这是协议的参数。参考课件里，a 记作 q 下标 a，q 记作 q 下标 r。 于是有两个二项分布。A(i, n)：m 减 n 个空闲节点里，恰好有 i 个发新分组的概率，等于组合数 C(m 减 n, i)，乘 a 的 i 次方，乘 1 减 a 的 m 减 n 减 i 次方。R(i, n)：n 个积压节点里，恰好有 i 个重传的概率，等于 C(n, i) 乘 q 的 i 次方，乘 1 减 q 的 n 减 i 次方。 算一个例子：m 等于 4，n 等于 2，a 等于 0.1，q 等于 0.3。两个空闲节点：A(0,2) 等于 0.9 的平方，0.81；A(1,2) 等于 2 乘 0.1 乘 0.9，0.18；A(2,2) 等于 0.01。两个积压节点：R(0,2) 等于 0.7 的平方，0.49；R(1,2) 等于 2 乘 0.3 乘 0.7，0.42；R(2,2) 等于 0.09。下一页用它们写出转移概率。
