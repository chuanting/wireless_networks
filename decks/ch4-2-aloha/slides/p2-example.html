例题：一条信道最多能接多少个终端？

题目

若干终端用纯 ALOHA 与主机通信，信道速率 2.4 kb/s。每个终端平均每 3 分钟发一个 200 bit 的帧。最多能容纳多少个终端？改用时隙 ALOHA 呢？

①

每个终端的平均速率

200 bit ÷ 180 s ≈ 1.11 bit/s

②

纯 ALOHA 最多用掉 18.4% 的信道

2400 × 0.184 ≈ 441 bit/s

③

能容纳的终端数

N ≤ 441 ÷ 1.11 ≈ 397 个

④

时隙 ALOHA 最多用掉 36.8%

2400 × 0.368 ≈ 883 bit/s

⑤

能容纳的终端数

N ≤ 883 ÷ 1.11 ≈ 794 个

注意

这是理论上限。实际系统要留余量——第三部分会看到，负荷太接近上限，系统会不稳定。

【3 分钟】 一道例题：若干终端用纯 ALOHA 与主机通信，信道速率 2.4 kb/s，每个终端平均每 3 分钟发一个 200 bit 的帧。问最多能容纳多少个终端？改用时隙 ALOHA 呢？ 第一步，每个终端的平均速率：200 bit 除以 180 秒，约 1.11 bit 每秒。 第二步，纯 ALOHA 最多只能用掉信道的 18.4%，所以能成功传送的速率最多是 2400 乘 0.184，约 441 bit 每秒。 第三步，终端数 N 乘 1.11 不能超过 441，所以 N 最多约 397 个。 改用时隙 ALOHA：最多用掉 36.8%，约 883 bit 每秒，N 最多约 794 个，正好翻倍。 注意，这是理论上限。实际系统的负荷要留余量，因为负荷太接近上限时，系统会变得不稳定，这是第三部分的内容。 [验算：2400 × 0.18394 / 1.1111 = 397.3；2400 × 0.36788 / 1.1111 = 794.6。参考课件里写的 396、793，是中间结果取整造成的差别。]
