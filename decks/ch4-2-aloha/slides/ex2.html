练习（二）：平衡点、转移概率与伪贝叶斯

④

时隙 ALOHA（无限源），λ = 0.3。求 G·exp(−G) = 0.3 的两个解，哪个稳定？

⑤

m = 3，a = 0.1，q = 0.5，当前 n = 1。求 P(1→0)、P(1→1)、P(1→2)、P(1→3)。

⑥

λ = 0.2，ñ = 3，接下来 4 个时隙的反馈依次为 e、e、0、1。求每个时隙的 q 和更新后的 ñ。

【4 分钟 · 参考答案】 ④ 两个解约为 G = 0.489 和 G = 1.781。小的那个稳定，大的那个不稳定（以平均趋势来说）。 ⑤ 两个空闲节点：A(0,1) = 0.81，A(1,1) = 0.18，A(2,1) = 0.01；一个积压节点：R(0,1) = 0.5，R(1,1) = 0.5。P(1→0) = 0.81 × 0.5 = 0.405；P(1→1) = 0.18 × 0.5 + 0.81 × 0.5 = 0.495；P(1→2) = 0.18 × 0.5 = 0.090；P(1→3) = 0.01。合计 1。平均下一状态 0.705，漂移 -0.295。 ⑥ 时隙 1：q = 1/3 = 0.333，碰撞，ñ = 3 + 0.2 + 1.392 = 4.592。时隙 2：q = 0.218，碰撞，ñ = 6.184。时隙 3：q = 0.162，空闲，ñ = 5.384。时隙 4：q = 0.186，成功，ñ = 4.584。 想一想：为什么一次碰撞后，增加真实积压与增加估计 ñ 是两件事？真实的积压由新到达和成功离开决定；估计的上调是从反馈得到的信息修正，旧的分组互撞并不产生新分组。 [验算：④ ⑤ ⑥ 用程序核对。]
