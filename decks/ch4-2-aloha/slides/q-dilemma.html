重传概率 q 的两难

q 大：重传得快

好处：轻载时积压的分组很快重发，时延小。

坏处：G(n) 随 n 涨得快，积压不多就越过不稳定点。q = 0.15：平均约 7 个时隙重传一次。

q 小：重传得慢

好处：G(n) 涨得慢，不容易堵塞。

坏处：每个积压的分组要等很久，时延大。q = 0.05：平均 20 个时隙重传一次。

更糟：无限源：新分组直接发时，G(n) = λ + nq 随 n 无限增大，成功概率趋于 0。任何固定的 q > 0，只要积压足够大，平均趋势就是一路上涨。

出路：q 不能固定，要随积压数调整。

【3 分钟】 所以重传概率 q 陷入两难。q 大，重传得快：轻载时积压的分组很快就重发，时延小；但 G(n) 随 n 涨得快，积压没多少，就越过了不稳定点。比如 q = 0.15，积压的分组平均 1/q ≈ 7 个时隙重传一次。q 小，重传得慢：G(n) 涨得慢，不容易堵塞；但每个积压的分组要等很久，时延大。q = 0.05，平均要等 20 个时隙。 更糟的是，在无限源模型下：新分组到达后下一个时隙直接发，积压的分组每个时隙以 q 重传。那么一个时隙里成功的精确概率是 e^(−λ) (1 − q)^n [λ + n q/(1 − q)]：对任何固定的 0 < q < 1，当 n 趋于无穷，它趋于 0（程序核对过：q = 0.1，λ = 0.3，n = 500 时小于 10 的负 15 次方）。所以只要积压足够大，平均趋势就是上涨，而随机波动迟早会把积压推到那里。q = 1 也不行：n ≥ 2 时全碰撞。 注意：这个结论限定在这个模型和固定 q 的重传规则，不推广到所有 ALOHA 的变体。 出路只有一个：q 不能固定，要随积压数 n 调整。积压多，就让每个节点少发一点；积压少，就多发一点。目标是让 G 一直待在 1 附近。这就是第四部分的伪贝叶斯算法。 [平均等待：每个时隙以概率 q 重传，等待的时隙数服从几何分布，平均 1/q。]
