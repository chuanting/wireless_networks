【4 分钟 · 进阶，可略】 把第 14 到 16 页的例子用多项式再走一遍：数据 1101，g = 1011。 起点：补 3 个 0 以后是 D^6 + D^5 + D^3，也就是 1101000。 第一步：最高次是 D^6，加上 D^3·g = D^6 + D^4 + D^3 把它消掉，剩下 D^5 + D^4。比特串上就是 1101000 ⊕ 1011000 = 0110000。 第二步：最高次是 D^5，加 D^2·g = D^5 + D^3 + D^2，剩下 D^4 + D^3 + D^2。 第三步：最高次是 D^4，加 D·g = D^4 + D^2 + D，剩下 D^3 + D。 第四步：最高次是 D^3，加 1·g = D^3 + D + 1，剩下 1。1 的次数是 0，比 g 的最高次 3 小，不能再除了，停止。 四步所加的 D^3、D^2、D、1 合起来是商 q = D^3 + D^2 + D + 1，剩下的 1 是余式，也就是 001，即校验位。 所以 D^6 + D^5 + D^3 = q·g + 1。两边加 1（1 + 1 = 0）得 D^6 + D^5 + D^3 + 1 = q·g。左边正是发送的帧 1101001，右边说明它是 g 的倍数。所有合法的帧都是 g 乘上某个多项式得到的，g “生成”了它们，这就是“生成多项式”名字的来由。 右边的公式只是把这个过程写成一行：C(D) = 余式 [ S(D)·D^L ÷ g(D) ]。S(D) 是数据；乘 D^L 是补 L 个 0；÷ g(D) 是做模 2 长除；取余式就是校验位 C(D)。 选讲：如果有同学想看真实长度的例子：数据 10110111，CRC-16，补 16 个 0 后做长除。从左数，在第 1、2、4、5、7 位首位为 1，各异或一次 g，共 5 次，余数 0000001110110010，发送序列 10110111 0000001110110010，共 24 位。（注意：这里的 1、2、4、5、7 是做除法时遇到首位为 1 的位置，不是数据本身为 1 的位置。） [验算：q·g（模 2 乘法）= 1111 × 1011 = 1101001，等于发送的帧；每一步的剩余多项式和比特串都用程序核对过；CRC-16 例子的余数和 5 次异或已用程序核对。]
