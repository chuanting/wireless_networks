【4 分钟 · 重点】 停等式到底有多慢？先算没有差错的情形。 先定义三个量：TD 是发出一帧要多久，等于帧长除以速率；Tp 是单程传播时延，信号走一趟要多久；a 等于 Tp 除以 TD，是相对时延。 停等式每个周期：发 TD，然后空等一个来回 2Tp（假设 ACK 很短，它的发送时间忽略）。真正在发送的只有 TD，所以链路利用率 U = TD / (TD + 2Tp) = 1 / (1 + 2a)。 例 ①：两栋楼之间 1 km 光纤，100 Mb/s，1500 字节。TD = 12000 位 ÷ 10^8 b/s = 120 微秒；信号在光纤里约 2×10^8 米/秒，Tp = 1000 ÷ (2×10^8) = 5 微秒；a ≈ 0.042。U = 1/(1 + 0.083) ≈ 92%。很高！ 例 ②：卫星链路，1 Mb/s，1500 字节。TD = 12 毫秒；卫星来回时延很长，单程 Tp 约 240 毫秒；a = 20。U = 1/(1 + 40) ≈ 2.4%。链路 97.6% 的时间都在空等 ACK！ 结论：a 越大，停等式越糟。传播时延比发送时间大得多的链路（卫星、跨洋光缆），停等式几乎没法用。 [验算：12000/10^8 = 1.2×10^-4 s = 120 μs；1/(1+2×0.0417) = 0.923；1/(1+40) = 0.0244。]
