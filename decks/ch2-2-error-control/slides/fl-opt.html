【4 分钟 · 推导】 写出效率。假设窗口足够大（选择重发），只考虑头尾开销和重发：U = ld/(ld + lh) × (1 − pb)^(ld + lh)。第二步：取对数，ln U = ln ld − ln(ld + lh) − (ld + lh)c，其中 c = −ln(1 − pb) ≈ pb（误码率很小时）。对 ld 求导，令导数为 0：1/ld − 1/(ld + lh) − c = 0。第三步：整理成 c ld^2 + c lh ld − lh = 0，取正根 ld* = [−lh + √(lh^2 + 4 lh/c)]/2，pb 很小时 ld* ≈ √(lh/pb)。 例：lh = 64，pb = 10^-4：近似 √(64/10^-4) = 800 位；精确值 ≈ 769 位，最高效率 ≈ 85%。规律：信道好 100 倍（pb 减小到 1/100），最佳帧长长 10 倍；头尾加倍，最佳帧长长约 1.4 倍。pb = 10^-5 时最佳约 2498 位，效率约 95%。 [验算：程序解二次方程得 768.6；在 ld 上数值扫描 U，最大值位置相同。]
