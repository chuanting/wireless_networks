窗口足够大（至少 1 + 2a）；定时器等于一个来回；ACK 不丢、不占时间。返回 n 里每错一帧，要多发 1 + 2a 个帧。

时延越大、误帧率越高，选择重发的优势越明显；代价是接收方要有缓存和排序能力。

【3 分钟】 三种 ARQ 的效率（窗口足够大，定时器等于一个来回，ACK 不丢也不占时间）。选择重发：每帧平均发送 1/(1 − p) 次，管道总是满的，U = 1 − p。停等式：U = (1 − p)/(1 + 2a)。返回 n：每错一帧，要多发 1 + 2a 个帧（窗口已发出但被接收方丢弃的那些加上出错的那一帧），平均成功发送一帧要发 1 + 2a·p/(1 − p) 个帧，所以 U = (1 − p)/(1 + 2ap)。 例：卫星链路 a = 20，p = 0.1：停等式 2.2%，返回 n 18%（0.9/(1 + 40 × 0.1) = 0.9/5），选择重发 90%。停等式 2.2%，返回 n 提高到 18%，是 8 倍；但 p = 0.1 时，返回 n 的大部分带宽仍浪费在重发上。 注意模型的前提：窗口够大。选择重发有错时，窗口还要等重发的帧被确认才能滑动，所以窗口要比 1 + 2a 更大才能不卡住（仿真：a = 4，p = 0.1，窗口 36 时 0.900，窗口 9 时只有 0.63）。返回 n 的窗口超过 1 + 2a 后效率不再变化。 [验算：时隙级仿真，a = 4，p = 0.1：停等式 0.0998（公式 0.100），返回 n（n = 9）0.5006（公式 0.500），选择重发（n = 36）0.9002（公式 0.900）。]
