序号不能无限增长：模 m 之后，窗口不能太大

窗口 n 与序号个数 m

返回 n

n ≤ m − 1

选择重发

n ≤ m / 2

HDLC：m = 8（3 位序号），返回 n 的窗口最大 7。

反例：返回 n，m = 8，窗口 n = 8。第一轮发 8 帧，全部被 B 收到，B 的 RN 回到 0。情形 A：ACK 全部到达，A 发新的 8 帧，序号还是 0 到 7。情形 B：ACK 全部丢失，A 超时，重发同样的 8 帧，序号也是 0 到 7。两种情形下，B 收到的序号完全一样，无法区分。

所以 n = m 不行：接收方分不清“新的一轮”还是“旧帧的重发”。

【3 分钟】 序号不能无限增长：用模 m 表示，例如 3 位序号：0、1、……、7、0、1、……（m = 8）。窗口 n 不能太接近 m，否则接收方分不清是新帧还是旧帧的重发。结论：返回 n：n ≤ m − 1；选择重发：n ≤ m/2。HDLC：m = 8（3 位序号），返回 n 的窗口最大 7。 反例：返回 n，m = 8，窗口 n = 8。第一轮发 8 帧 0 到 7，全部被 B 收到，B 的 RN 回到 0。情形 A：ACK 全部到达，A 发新的 8 帧，序号还是 0 到 7；情形 B：ACK 全部丢失，A 超时，重发同样的 8 帧，序号也是 0 到 7。两种情形下，B 收到的序号完全一样，无法区分，只能出错。所以 n = m 不行。 选择重发为什么要 n ≤ m/2：接收方的窗口和发送方的窗口各占 n 个序号，两个窗口不能有重叠，所以 m 至少是 2n。
