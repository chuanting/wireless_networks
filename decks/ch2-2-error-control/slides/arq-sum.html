第二部分 · 小结

ARQ：一路改进下来的逻辑

1

基本机制：CRC 检错 + ACK + 定时器 + 重发

收错了就不回确认，发送方超时重发。

2

序号 SN / RN：解决重复和误确认

停等式只要 1 位；没有序号，ACK 丢了会重复交付。

3

停等式的瓶颈：利用率 U = (1 − p) / (1 + 2a)

时延越大越浪费，卫星上只有 2% 左右。

4

滑动窗口：连续发，最多 n 个未确认；n ≈ 1 + 2a

返回 n：错了一帧，后面全重发。选择重发：只重发错的，接收方要缓存。

5

效率：2.2% → 18% → 90%（卫星，p = 0.1）

序号模 m：返回 n 要 n ≤ m − 1，选择重发要 n ≤ m / 2。

下一步：帧到底切多长？—— 最佳帧长。
