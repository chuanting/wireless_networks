【2 分钟 · 进阶，可略】 前面一直在说 g，它的正式名字叫“生成多项式”。这一页回答第一个问题：为什么一串比特会被叫作“多项式”。 先看十进制：305 的意思是 3×100 + 0×10 + 5×1，每个数位有一个“权重”，从右往左是 1、10、100。二进制同理。多项式的写法是：不管权重具体是多少，只用一个符号 D 来记“这是第几位”。 规则：从右往左数，最右一位是第 0 位，往左依次是第 1 位、第 2 位……第 i 位是 1，就写一项 D 的 i 次方；是 0 就不写。D 的 0 次方就是 1，D 的 1 次方写成 D。所以 1011 ↔ D^3 + D + 1。注意：D 不是要求解的未知数，也不用代入数值，它只是一个“占位符”，用来记录每个 1 站在第几位。 三个例子：1101 ↔ D^3 + D^2 + 1，是后面要用的数据；1101000 ↔ D^6 + D^5 + D^3，是数据后面补 3 个 0，每一项的次数都变大了，下一页会用到；反过来 D^4 + D + 1 ↔ 10011，缺的 D^3、D^2 两项对应的位补 0。 真实的 CRC-16：g(D) = D^16 + D^15 + D^2 + 1，写成比特串是 1 1000 0000 0000 0101，一共 17 位，所以 L = 16。 [验算：1011 → 次数 {3,1,0}；1101 → {3,2,0}；1101000 → {6,5,3}；10011 → {4,1,0}；0x18005 → {16,15,2,0}。]
