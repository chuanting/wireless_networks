【3 分钟 · 进阶，可略】 比特串也能写成多项式：从右往左数，最右一位是第 0 位，往左是第 1 位、第 2 位……第 i 位是 1，就写一项“D 的 i 次方”。D 不是要你求的未知数，只是占位符，记录每个 1 站在第几位。例：1011 就是 D^3 + D + 1；1101 是 D^3 + D^2 + 1。 换成多项式后，CRC 的三个动作各有名字：补 3 个 0 就是乘以 D^3，整串向左挪 3 位；异或就是同类项相消（1 + 1 = 0）；长除法的一步，是把 g 乘上 D 的某次幂对齐到最高位再相加，把最高次项消掉。所以整个 CRC，就是多项式的乘法、加法、除法，和中学学的一样，唯一的区别是系数相加按 1 + 1 = 0 算，没有进位。 前面一直叫“生成多项式 g”，就是这个意思。CRC-16 的生成多项式是 D^16 + D^15 + D^2 + 1，17 位，所以 L = 16。 用多项式走一遍：数据 1101 对应 D^3 + D^2 + 1，补 3 个 0 是 D^6 + D^5 + D^3，除以 g = D^3 + D + 1，商 D^3 + D^2 + D + 1，余式 1，即 001。发送的帧 D^6 + D^5 + D^3 + 1 = (D^3 + D^2 + D + 1)(D^3 + D + 1)，是 g 的倍数。所有合法的帧，都是 g 乘上某个多项式“生成”出来的，这就是“生成多项式”名字的由来。
