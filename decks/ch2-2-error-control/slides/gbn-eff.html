【4 分钟 · 推导】 返回 n 的效率。设帧长固定，ACK 很短（忽略它的发送时间），误帧率 p。 先算成功发一帧，平均要发多少个帧。一帧发了 i 次才成功，意味着前 i−1 次都出错；每出错一次，要重发整整 n 帧，所以这一帧总共对应发了 1 + (i−1)n 个帧。 取平均：N_f = 1 + n × E[i−1]。而 E[i] = 1/(1−p)（上一页算过），所以 E[i−1] = 1/(1−p) − 1 = p/(1−p)。于是 N_f = 1 + np/(1−p) = [1 + (n−1)p]/(1−p)。 利用率：如果窗口足够大，n ≥ 1 + 2a，管道总是满的，有效帧占比是 1/N_f，即 U = (1−p)/[1 + (n−1)p]。如果窗口比 1 + 2a 小，管道没填满，还要再乘一个 n/(1+2a)。p = 0 时，U = 1。 例：卫星链路 a = 20，p = 0.1。要填满管道，n = 41。U = 0.9/(1 + 40×0.1) = 0.9/5 = 18%。 对比停等式的 2.2%，提高到 8 倍。但 p = 0.1 时，大部分带宽仍浪费在重发上——因为每错一帧要重发 41 帧！这就是返回 n 的缺点，下面用选择重发来改进。 [验算：N_f = 1 + 41×0.1/0.9 = 5.56，U = 1/5.56 = 0.18。]
