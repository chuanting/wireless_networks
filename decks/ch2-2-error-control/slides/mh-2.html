第三部分 · 最佳帧长 · 多跳路径

最佳分组长度：K* = √( M V / (j − 1) )

推导：把 ⌈M/K⌉ 近似成 M/K

C T ≈ M + M V/K + (j − 1)(K + V)

对 K 求导，令其为 0：

− M V/K² + (j − 1) = 0

结果

K* = √( M V / (j − 1) )

消息越长、头尾越大，分组应越长；跳数越多，分组应越短。

例：M = 100 KB = 8×10⁵ 位，V = 320 位（40 字节头部），j = 5 条链路

【3 分钟】 这一页求最优的分组长度 K。把 ⌈M/K⌉ 近似成 M/K，则 C·T ≈ M + MV/K + (j−1)(K+V)。对 K 求导，令导数为 0：−MV/K² + (j−1) = 0，解得 K* = √[MV/(j−1)]。 规律：消息越长（M 大）、头尾越大（V 大），分组应该越长；跳数越多（j 大），分组应该越短。 例：消息 100 KB = 8×10^5 位，头部 40 字节 = 320 位，经过 j = 5 条链路。K* = √(8×10^5 × 320/4) = √(6.4×10^7) = 8000 位 = 1000 字节。这个数和我们实际网络里常见的 1000 多字节的分组长度很接近。 下面的柱状图是不同 K 对应的“额外时间”，相对只发 M 位而言：K = 800 位（100 字节）时 40.6%；K = 2000 位时 17.2%；4000 位 10.2%；8000 位 8.2%，最小；16000 位 10.2%；32000 位 17.2%。左右对称，最低点正好在 8000。 [验算：C·T = M + ⌈M/K⌉V + (j−1)(K+V)。K = 8000：8×10^5 + 100×320 + 4×8320 = 865280，额外 8.16%。K = 800：8×10^5 + 1000×320 + 4×1120 = 1124480，额外 40.56%。]
