第一部分 · 差错检测 · CRC · 多项式视角（进阶，可略）

换成多项式后，CRC 的三个动作各有名字

① 补 3 个 0

＝ 乘以 D3

十进制

305 → 30500，就是 305 × 100

比特串

1101 → 1101000

多项式

(D3 + D2 + 1) × D3

= D6 + D5 + D3

每项次数都加 3：整串向左挪 3 位。

② 异或（模 2 加法）

＝ 同类项相消

比特串

1101 ⊕ 1011 = 0110

多项式

(D3 + D2 + 1) + (D3 + D + 1)

= D2 + D

因为 1 + 1 = 0：相同的项成对消失，留下的就是两串里不同的位。

③ 长除法的一步

＝ 把最高次项消掉

比特串

1101000 ⊕ 1011000 = 0110000

多项式

D3·g = D6 + D4 + D3

(D6 + D5 + D3) + (D6 + D4 + D3)

= D5 + D4

把 g 对齐到首位，就是乘上 D3。加上以后，最高次的 D6 消失了。

所以整个 CRC，就是多项式的乘法、加法、除法，和中学学的一样。唯一的区别：系数相加按 1 + 1 = 0 算，没有进位。

【3 分钟 · 进阶，可略】 为什么要折腾成多项式？因为 CRC 里的三个动作，在多项式里都有现成的名字，而且这些名字能帮我们证明 CRC 为什么管用。 动作一，补 L 个 0。十进制里 305 后面补两个 0 变成 30500，就是乘以 100。二进制里 1101 补 3 个 0 变成 1101000，对应的多项式从 D^3 + D^2 + 1 变成 D^6 + D^5 + D^3，每一项的次数都加 3，也就是乘以 D^3。 动作二，异或。1101 ⊕ 1011 = 0110。写成多项式：(D^3 + D^2 + 1) + (D^3 + D + 1)。D^3 出现两次，1 也出现两次，1 + 1 = 0，成对消失，剩下 D^2 + D，正好是 0110。所以异或就是“相同的项消掉，不同的项留下”。 动作三，长除法的一步。被除数的首位是 1，就异或一次 g，而且 g 要先对齐到首位，“对齐”就是乘以 D 的某次方。例：D^6 + D^5 + D^3 加上 D^3·g（也就是 1101000 ⊕ 1011000 = 0110000），D^6 消掉了，剩下 D^5 + D^4。 整个 CRC 就是多项式的乘法、加法、除法；唯一的区别是系数相加按 1 + 1 = 0 算，没有进位。 [验算：D^6 + D^5 + D^3 加 D^3·(D^3 + D + 1) 得 D^5 + D^4，即 0110000；1101 ⊕ 1011 = 0110 对应 D^2 + D。]
