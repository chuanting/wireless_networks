第一部分 · 差错检测 · 奇偶校验（可略）

一般形式：多个校验位，各查数据的一个子集

例：K = 3 个信息位 S1 S2 S3，L = 4 个校验位 C1 C2 C3 C4

C1 = S1 ⊕ S3

C2 = S1 ⊕ S2 ⊕ S3

C3 = S1 ⊕ S2

C4 = S2 ⊕ S3

每个校验位只检查信息位的一部分（⊕ = 异或）。

发送：信息 100

C1 = 1 ⊕ 0 = 1

C2 = 1 ⊕ 0 ⊕ 0 = 1

C3 = 1 ⊕ 0 = 1

C4 = 0 ⊕ 0 = 0

校验位 1110，发出的序列 100 1110。

接收：收到 1011110（第 2 位错了）

收到的信息位是 101，重新算校验位：

C1 = 1 ⊕ 1 = 0　　C2 = 1 ⊕ 0 ⊕ 1 = 0

C3 = 1 ⊕ 0 = 1　　C4 = 0 ⊕ 1 = 1

算得 0011，与收到的 1110 不同 → 有错。

这类“按规则异或”的校验码统称线性分组码。下面要学的 CRC，是其中最重要的一员。

【2 分钟 · 可略】 把校验位推广：不止一个，而是 L 个，每个只检查信息位的一个子集。 例：3 个信息位 S1 S2 S3，4 个校验位：C1 = S1 ⊕ S3；C2 = S1 ⊕ S2 ⊕ S3；C3 = S1 ⊕ S2；C4 = S2 ⊕ S3。 发送：信息位 100：C1 = 1 ⊕ 0 = 1；C2 = 1 ⊕ 0 ⊕ 0 = 1；C3 = 1 ⊕ 0 = 1；C4 = 0 ⊕ 0 = 0。校验位 1110，发出的序列是 1001110。 接收：假设第 2 位出错，收到 1011110。收到的信息位是 101，重新算校验位：C1 = 1 ⊕ 1 = 0；C2 = 1 ⊕ 0 ⊕ 1 = 0；C3 = 1 ⊕ 0 = 1；C4 = 0 ⊕ 1 = 1。算得 0011，和收到的 1110 不同，所以有错。 这类“按规则异或”的校验码统称线性分组码。上一页的二维校验，也是它的特例。下面要学的 CRC，是其中最重要的一员，因为它可以用很简单的硬件实现，而且对突发错误特别有效。 [提示：这一页是为 CRC 作铺垫，时间紧可以跳过，直接讲 CRC 也不影响理解。]
