总结

一页回顾今天的内容

差错检测

加冗余，重算比对。奇偶校验只能发现奇数个错；CRC = 用 g 做模 2 除法，发现所有 ≤ L 位的突发错误，漏检约 2 的 −L 次方。

ARQ 基础

ACK + 定时器 + 重发；序号 SN / RN 防重复、防误确认；停等式利用率 U = (1 − p) / (1 + 2a)。

滑动窗口

返回 n：错一帧，后面全重发，U = (1 − p) / (1 + (n − 1)p)；选择重发：只重发错的，U = 1 − p。窗口 n ≈ 1 + 2a。

序号空间

模 m：返回 n 要 n ≤ m − 1，选择重发要 n ≤ m / 2；HDLC 用 m = 8，窗口最大 7。

最佳帧长

单链路 ld* ≈ √( lh / pb )；多跳 K* = √( M V / (j − 1) )；语音要短；长度应由网络统一定。

下一节（2.3）：把组帧、CRC、返回 n 装配起来，就是 HDLC 协议。
