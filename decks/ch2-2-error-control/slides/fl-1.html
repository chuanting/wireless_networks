帧太短不好，帧太长也不好

帧太短

每帧都要带头尾（地址、序号、CRC、Flag……），共 lh 位。负荷越短，头尾占的比例越大。

有效比例 = ld / (ld + lh)

帧太长

帧越长，里面有错的概率越大（p ≈ lf × pb），要重发的次数越多。

一次成功的概率 = (1 − pb) 的 lf 次方

数字例子：头尾 lh = 64 位，误比特率 pb = 10 的 −4 次方

【3 分钟】 帧该切多长？先看两个相反的因素。 帧太短：每帧都要带头尾——地址、序号、CRC、Flag——假设共 l_h 位。负荷 l_d 越短，头尾占的比例越大。有效比例 = l_d/(l_d + l_h)。 帧太长：帧越长，里面有一位出错的概率越大，帧错的概率 p ≈ l_f × p_b（l_f = l_d + l_h 是整帧长度），重发的次数越多。一次就成功的概率 = (1−p_b)^l_f。 数字例子：头尾 l_h = 64 位，误比特率 p_b = 10^-4。 l_d = 100：有效比例 0.61，成功概率 0.98，乘积 0.60；l_d = 400：0.86 × 0.95 = 0.82；l_d = 800：0.93 × 0.92 = 0.85，最高；l_d = 1600：0.96 × 0.85 = 0.81；l_d = 8000：0.99 × 0.45 = 0.44。 先升后降。一个因素随帧长增大变好，另一个变坏，所以一定有个最佳点。下一页把它推出来。 [验算：ld/lf：100/164 = 0.610；800/864 = 0.926；(1−10^-4)^864 = 0.917；乘积 0.849。]
