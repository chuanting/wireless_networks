② 取对数，对 ld 求导，令导数为 0

ln U = ln ld − ln(ld + lh) − (ld + lh)c

其中 c = −ln(1 − pb) ≈ pb（误码率很小时）。

1/ld − 1/(ld + lh) − c = 0

③ 整理，得到最佳负荷长度

c ld² + c lh ld − lh = 0　⟹　ld* = [ −lh + √( lh² + 4lh / c ) ] / 2 ≈ √( lh / pb )

例：lh = 64，pb = 10 的 −4 次方

近似 √(64/10⁻⁴) = 800 位；精确值 ≈ 769 位，最高效率 ≈ 85%。

规律

信道好 100 倍（pb 减小到 1/100），最佳帧长长 10 倍；头尾加倍，最佳帧长长约 1.4 倍。

【4 分钟 · 推导】 把上一页的两个因素相乘，就是效率：U = [l_d/(l_d + l_h)] × (1−p_b)^(l_d + l_h)。这里假设窗口足够大（选择重发），只考虑头尾开销和重发。 求最大值：对 l_d 求导。取对数更方便：ln U = ln l_d − ln(l_d + l_h) − (l_d + l_h)·c，其中 c = −ln(1−p_b)，当误码率很小时 c ≈ p_b。 对 l_d 求导并令其为 0：1/l_d − 1/(l_d + l_h) − c = 0。通分：l_h/[l_d(l_d + l_h)] = c，整理成 c·l_d² + c·l_h·l_d − l_h = 0。 解这个一元二次方程：l_d* = [−l_h + √(l_h² + 4 l_h/c)]/2。当 l_h 远小于 l_d* 时，约等于 √(l_h/p_b)。 例：l_h = 64，p_b = 10^-4：近似 √(64/10^-4) = √640000 = 800 位；精确值约 769 位，对应的最高效率约 85%。 规律：最佳帧长和 √(l_h/p_b) 成正比。信道好 100 倍（p_b 减小到 1/100），最佳帧长长 10 倍；头尾加倍，最佳帧长长约 1.4 倍。这与直觉一致：信道好，可以用更长的帧减少头尾开销；信道差，要用更短的帧，减少重发的代价。 [注：如果是停等式，还要把传播时延带来的空等算进去，最佳帧长会更长一些。]
