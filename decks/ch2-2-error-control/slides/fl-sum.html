第三部分 · 小结

最佳帧长：都是“两头夹击”的折中

单条链路

短 → 头尾占比大；长 → 出错重发多。

最佳负荷长度 ld* ≈ √( lh / pb )

多跳路径

小 → 头尾总开销大；大 → 流水线填充慢。

最佳分组长度 K* = √( M V / (j − 1) )

实时语音

要攒够 K 位才能发：打包时延 = K / R，所以分组要很短（< 500 位）。

网络整体

慢货车效应：长分组堵短分组，帧长应由网络统一规定。

一个通用的方法：写出“总代价”的表达式，求导，找极小点。第 3 章讲排队时延时还会再用。

【1.5 分钟】 最佳帧长小结，三个场景，一个共同的方法。 单条链路：帧短，头尾占比大；帧长，出错重发多。最佳负荷长度约等于 √(l_h/p_b)。 多跳路径：分组小，头尾总开销大；分组大，流水线填充慢。最佳分组长度 K* = √[MV/(j−1)]。 实时语音：要攒够 K 位才能发，打包时延 K/R，所以分组要很短。 网络整体：慢货车效应，长分组堵短分组，所以帧长应由网络统一规定。 共同的方法：写出总代价的表达式，求导，找极小点。这个“两头夹击取折中”的思路，在后面还会反复出现，比如第 3 章的排队时延分析。
