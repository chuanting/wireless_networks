定时器

DATA SN=0（重发）

SN < RN：丢弃

ACK RN=1

DATA SN=1

收到 RN=1 > SN=0：发 SN=1

ACK RN=2

帧里加两个序号：SN 是这一帧的编号；RN 是期望收到的下一帧的编号（已正确收到的最大编号加 1）。B 收到 SN = RN 的帧：交付，RN 加 1；收到 SN 小于 RN 的帧：是重复，丢弃，但仍回 ACK(RN)。停等式里 SN 和 RN 只要 1 位：0、1 交替。

重复帧被丢弃，上层只收到一份。

【3 分钟】 解决办法：给帧编序号。帧里加两个序号：SN，我这一帧的编号；RN，我期望收到的下一帧的编号，也就是已经正确收到的最大编号加 1。B 的规则：收到 SN = RN 的帧：交付，RN 加 1；收到 SN 小于 RN 的帧：是重复，丢弃，但仍回 ACK(RN)。停等式里，SN 和 RN 只需要 1 位（模 2）：0、1 交替就够了。 看图：DATA SN=0 到达，B 交付，RN 变成 1，ACK RN=1 丢了；A 超时重发 DATA SN=0；B 发现 SN = 0 小于 RN = 1，是重复，丢弃，但仍回 ACK RN=1；A 收到 RN = 1 大于 SN = 0，确认成功，发下一帧 SN = 1。
