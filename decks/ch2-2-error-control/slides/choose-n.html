窗口 n 取多大最合适？

看返回 n 的利用率随 n 怎么变

• n < 1 + 2a：管道没填满，n 越大，U 越高。

• n ≥ 1 + 2a：管道已满，再加大 n 只会让每次出错重发更多，U 反而下降。

最佳窗口

n = ⌈ 1 + 2a ⌉

1 + 2a 的另一种读法

就是“带宽 × 往返时延”（带宽时延积）换算成帧数。跨洋光缆：10⁹ b/s × 0.1 s = 10⁸ 位 ≈ 12.5 MB 同时在路上！

所以 HDLC 的窗口 7 够吗？

对 a 很小的地面链路够了；卫星上就要用扩展序号（窗口 127）。

【3 分钟】 窗口 n 取多大？看返回 n 的利用率怎么随 n 变化： n 小于 1 + 2a 时，管道没填满，n 越大，利用率越高；n 大于等于 1 + 2a 时，管道已满，再加大 n 只会让每次出错重发更多，利用率反而下降。所以最佳窗口就是 n = ⌈1 + 2a⌉，窗口发完的时间约等于一个来回的时间：刚好把管道填满。 代入三条链路：校园网光纤 1 km：a = 0.042，n = 2 就够了；卫星链路：a = 20，n = 41；跨洋光缆 1 Gb/s，帧长 1500 字节，TD = 12 微秒，单程时延 50 毫秒，a ≈ 4167，n = 8335 帧！ 序号至少要几位？返回 n 要 n ≤ m−1，所以 m ≥ n+1；选择重发要 m ≥ 2n。卫星：返回 n 需要 m ≥ 42，6 位；选择重发需要 m ≥ 82，7 位。跨洋：返回 n 要 14 位，选择重发要 15 位。 1 + 2a 还有另一种读法：就是“带宽乘以往返时延”，也叫带宽时延积，换算成帧数。跨洋光缆：10^9 b/s × 0.1 s = 10^8 位，约 12.5 MB 同时在路上！ HDLC 的窗口最大 7，对 a 很小的地面链路够了；卫星上要用扩展序号（7 位，窗口 127）。 [验算：50 ms ÷ 12 μs = 4166.7，1 + 2×4166.7 = 8334.3 → 8335；log2(8336) ≈ 13.03 → 14 位；2×8335 = 16670 → 15 位。]
