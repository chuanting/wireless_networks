时延越大，越浪费：卫星上的停等式，链路 97% 的时间在空等。

【4 分钟】 停等式到底有多慢？先算无差错的情形。TD = 帧长 ÷ 速率，发出一帧要多久；Tp = 单程传播时延；a = Tp/TD，相对时延。一个周期：发 TD，再空等一个来回 2Tp（这里忽略 ACK 的发送时间和处理时间；若要计入，把分母的 2Tp 换成 2Tp + ACK 的发送时间）。利用率 U = TD/(TD + 2Tp) = 1/(1 + 2a)。 例一：两栋楼之间 1 km 光纤，100 Mb/s，帧长 1500 字节：TD = 12000 ÷ 10^8 = 120 μs；Tp = 1000 m ÷ 2×10^8 m/s = 5 μs；a ≈ 0.042；U = 1/(1 + 0.083) ≈ 92%。例二：卫星链路，1 Mb/s，帧长 1500 字节：TD = 12 ms；Tp ≈ 240 ms；a = 20；U = 1/(1 + 40) ≈ 2.4%。 再算有差错的情形：设一帧出错的概率为 p，第 i 次才发成功的概率 p^(i−1)(1 − p)，是几何分布；平均发送次数 E[N] = 1/(1 − p)。每次发送都占用一个周期（超时设为一个周期），所以 U = (1 − p)/(1 + 2a)，出错使利用率再乘上一个因子 (1 − p)。例：p = 0.1，卫星链路：U = 0.9/41 ≈ 2.2%，几乎没法用。 [验算：时隙级仿真，a = 4：p = 0 时 0.1111（公式 0.1111），p = 0.1 时 0.0998（公式 0.1000）。]
