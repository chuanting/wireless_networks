【2 分钟】 三种 ARQ 放在一起比较。 发送窗口：停等式是 1，另外两种是 n。接收方缓存：停等式 1 帧；返回 n 也是 1 帧，乱序的直接丢掉；选择重发要 n 帧，还要排序。出错后重发：停等式重发这一帧；返回 n 重发这一帧和后面的全部；选择重发只重发这一帧。序号：停等式 1 位；返回 n 要求 n ≤ m−1；选择重发要求 n ≤ m/2。 利用率（窗口足够大时）：三个公式。卫星例子：2.2%、18%、90%。 用在哪里：Wi-Fi（802.11）对每个单播帧都要确认，本质是停等式；HDLC 的可靠模式用的是返回 n；TCP 的选择确认（SACK）和 5G 的 RLC 层用的是选择重发的思想。 共同点：都是 CRC 检错、序号、定时器这三样东西，区别只在“怎么重发”。 [提示：这张表可以让学生拍照留着复习。]
