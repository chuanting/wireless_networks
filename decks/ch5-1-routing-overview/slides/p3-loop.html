【3 分钟】 分布式路由的一个典型问题：路由环路。 看图。原来 X 去 N 的路是经过 Y，Y 再直达 N。现在 Y 到 N 的链路断了。Y 知道了，就在自己的表里改成：去 N 经 X 走，因为它以为 X 还有别的路能到 N。可 X 的表还没更新，仍然写着：去 N 经 Y 走。 于是一个发往 N 的分组，到了 X，X 交给 Y；到了 Y，Y 又交回 X……在 X、Y 之间来回打转。它白白占用这条链路，最后还是到不了 N。 怎样止损？IP 分组头里有一个字段叫 TTL，生存时间。每经过一台路由器减 1，减到 0 就丢弃。比如从 64 开始，转发 63 次以后就被丢掉，不会永远转下去。IPv6 里这个字段叫 hop limit，跳数限制，作用一样。 TTL 只是保险丝：防止事故扩大，并不能消除事故。真正的办法是让各台路由器的表尽快一致。第 5.3 讲的距离矢量算法里，还会遇到这个问题，而且更严重，叫“计数到无穷”。
