宿舍联网，四种设备各做什么？

早期有线宿舍 · 用集线器把几台电脑接在一起

今天的宿舍 · 无线路由器常集成 Wi-Fi、交换和路由

中继器（集线器）

物理层 · 再生信号

一台电脑发出的信号被复制到其他端口，几台电脑共享带宽。

网桥（二层交换机）

链路层 · 看 MAC 地址

给室友传文件，交换机学到室友的端口后，只往那个端口发帧。

路由器

网络层 · 看目的 IP 地址

打开校外网页，路由器查表，把分组交给校园网的下一跳。

协议转换网关

上层 · 转换通信协议

温度传感器用 MQTT 上报，网关改用 HTTP 把读数发给管理平台。

选设备先看要完成什么任务。网速看链路和转发性能，价格看具体规格和功能。

电脑设置里的“默认网关”通常是出本子网的路由器。

【3 分钟】 先看两张情景示意图。早期的有线宿舍可以用集线器把几台电脑接在一起。集线器是多端口中继器：从一个口收到的信号，经过再生后从其他口送出去。电脑 A 给 B 传文件时，C 所在的端口也有同样的信号。大家共用一段带宽。 换成网桥或二层交换机以后，同一局域网里的电脑 A 仍然可以给 B 传文件。交换机从收到的帧学习“哪个 MAC 地址在哪个端口”。已经学到 B 的端口后，它只把发给 B 的这份单播帧送到那个端口。问学生：这时 C 的端口还有同样的帧吗？在这个已知目的端口的例子里，C 的端口不会收到这份帧。 再把目的地换成校外网站。宿舍里的默认网关通常就是出子网的路由器。它读取分组的目的 IP 地址，查转发表，把分组交给校园网里的下一跳。家用无线路由器常把无线接入点、二层交换机和路由功能放在同一个盒子里，因此同一个盒子可以既让手机接入 Wi-Fi，又负责出宿舍子网。 协议转换网关处理的是两端说法不同的问题。比如温度传感器用 MQTT 发布读数，管理平台接收 HTTP 请求。网关订阅温度读数，再用 HTTP 请求把读数交给平台。这里的网关做的是协议转换；电脑网络设置里的“默认网关”指负责出本子网的路由器。 用层次判断设备能读到什么，以及能做哪类决定。早期集线器共享链路，换交换机常能减少争用；实际速度还取决于链路速率、负载和设备转发能力。价格还受端口、支持速率和附加功能影响。 【收束提示】电脑设置里的“默认网关”通常是出本子网的路由器。
