每一行：去某个目的地，交给哪个邻居（下一跳），全程代价多少。

A 去 D：经 B 代价 2 + 5 = 7，经 C 代价 4 + 2 + 3 = 9，所以下一跳是 B。

转发只需要“下一跳”：整条路径不用记，交给下一台路由器去决定。

【3 分钟】 看左边这个网络：六台路由器 A 到 F，连线上的数字是链路的代价，可以理解为时延或者距离。 右边是路由器 A 的路由表，每个目的地一行，记两样东西：下一跳，也就是交给哪个邻居；代价，也就是到目的地全程的代价。 比如 A 去 D：有两种走法。经 B：A 到 B 是 2，B 到 D 是 5，合计 7。经 C：A 到 C 是 4，C 到 E 是 2，E 到 D 是 3，合计 9。所以 A 的表里，去 D 的下一跳是 B，代价 7。 再看 A 去 C：直达代价 4；经 B 是 2 + 3 = 5。直达更好，所以下一跳是 C。 请大家注意：A 的表里只记下一跳，不记整条路径。A 把去 D 的分组交给 B 以后，剩下的路怎么走，由 B 的表决定。这就是逐跳转发，下一页看。 这张表是怎么算出来的？就是下一讲的最短路由算法。
