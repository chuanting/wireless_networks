关于同一个目的网 N，表里怎样记

起点 D

D 直连 N，记为 1，并向邻居通告 1。

B 和 E 收到 D 的 1

两者都记 1 + 1 = 2，下一跳为 D。

A 收到 B 的 2

经 B 的候选为 1 + 2 = 3。

C 收到 E 的 2

C 经 E 到 N 为 1 + 2 = 3，向 A 通告 3。

现在 A 又收到 C 的通告 3。经 C 要多少？A 会改下一跳吗？

经 C 为 1 + 3 = 4，经 B 为 1 + 2 = 3。A 保留下一跳 B，到 N 的度量为 3。

【3 分钟】 沿用上一页的物理连线。覆盖住图，只把邻居报来的数告诉扮演 A 的同学。RIP 运用 Bellman–Ford 的距离向量更新。消息按右表顺序到达是其中一种可能，协议不要求全网同步。 目的地是 D 的直连网 N，D 先记接口代价 1。B 和 E 各经一段代价为 1 的链路到 D，所以对外通告 2。A 听到 B 的 2，先记“经 B，度量 3”。C 听到 E 的 2，记为 3，随后也把这个数告诉 A。 请学生只用 B、C 的通告算出两个候选并选择下一跳，然后点击揭晓。A 经 B 的候选是 3，经 C 的候选是 4，保留 B。路径为 A、B、D、网 N。其中从 A 到 D 有两段路由器间链路，再计入 D 到直连网 N 的 1，度量恰为 3。上一页经 C 的链路代价和较低，这一页经 B 的段数较少。 协议原文见 https://www.rfc-editor.org/rfc/rfc2453#section-3.4 和 https://www.rfc-editor.org/rfc/rfc2453#section-3.5 。该例采用通常的单位接口代价和可达的稳定网络。RIP 度量 16 表示不可达。
