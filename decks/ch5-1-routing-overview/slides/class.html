【讲读提示】开放最短路径优先（Open Shortest Path First，OSPF）和路由信息协议（Routing Information Protocol，RIP）都由路由器各自计算路径。两种协议拿什么信息来算？ 【3 分钟】 这些分类是相互独立的维度。决策地点指逻辑集中控制或各节点计算；转发依据指按目的地址查表或使用连接标识；性能准则可以是跳数、代价或其他目标；信息来源可以是本地、邻居的距离、路径或完整拓扑；适应性区分静态配置与动态更新。IP 逐包查表并不等于逐包重算路由。OSPF 在各路由器计算，使用区域内的完整拓扑。这里演示早期的热土豆规则。路由器 A 有两个出口，分别连到 B 和 C。假定两个端口同速、分组等长。新分组到达时，往 B 的队列有 4 包，往 C 的队列有 1 包，A 就把它放进往 C 的队列。过一会儿再来一包，两队列分别有 4、6 包，这次放进往 B 的队列。比较的都是 A 此刻的队列长度。即使经 C 要多走几跳，第一次仍选 C，所以局部少排队并不保证全程时延最小。 【收束提示】先看谁负责算路，再看网络变化时怎样更新。
