当堂检验：链路改价后，A 会换下一跳吗？

A 要发往 D 直连的目的网 N。两条路都畅通，只有 E–D 的双向代价从 1 升到 6。路由信息已更新。

可走的路径

改价后的链路代价（依次）

A 的出口队列（改价前后相同）

A → B → D → N

2，5，1

往 B 排 4 个分组

A → C → E → D → N

1，1，6，1

往 C 排 1 个分组

分别按 OSPF、RIP 和本讲的热土豆规则选下一跳。写出你比较的两个数。RIP 每个接口计 1，D 的直连网度量为 1。

OSPF

经 B 的总代价为 2 + 5 + 1 = 8，经 C 为 1 + 1 + 6 + 1 = 9。原来经 C 只需 4，现在改走 B。

RIP

B 通告 2，C 通告 3。A 各加 1 得到 3 和 4，仍选 B。链路改价没有改变跳数。

热土豆

本地队列长度为 4 和 1，仍选 C。路由器单凭这个队列快照，无法知道余下的路要花多少代价。

【讲读提示】A 要发往 D 直连的目的网 N。两条路都畅通，只有 E–D 的双向代价从 1 升到 6。路由信息已更新。 【3 分钟 · 先作答，再点击核对】 请学生独立写下三项选择，再让同桌检查每个数的单位。图里把最后一段 D 到 N 也列了出来，所以每条候选路线都有它的代价。 原来的带权总代价，经 B 是 8，经 C 是 4。改变 E 到 D 的代价后，经 C 多了 5，更新为 9，OSPF 把去 N 的下一跳从 C 改成 B。 RIP 的每个接口在本题里始终计 1，目的网和邻接关系都没有变化。B、C 通告的距离分别为 2、3。A 的候选是 3、4，仍然经 B。 热土豆例子只对这个分组作本地决定。两次观察中往 C 排队的分组都少，选 C。追问学生：即使三个算法中有两个选了同一个出口，能拿 OSPF 的 8 和 RIP 的 3 来比较好坏吗？它们各自采用不同的度量，数字只能在相应规则内比较。
