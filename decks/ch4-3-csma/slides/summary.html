一页回顾

CSMA

先听后说；别人开始后 τ 之内你还听不到，所以仍会碰撞。

β = τ / T

决定一切：越小越好；β 太大时，侦听还不如时隙 ALOHA。

通过率

β = 0.01：时隙 ALOHA 0.368，非坚持 CSMA 0.815，时隙 CSMA 0.865，CSMA/CD 0.968（理想模型的峰值）。

稳定

伪贝叶斯换个目标：q = min(√(2β)/ñ, √(2β))，新分组也先进积压。

实践

以太网：1-坚持 CSMA/CD + 二进制指数退避（共享半双工）；Wi-Fi：CSMA/CA，退避 + 确认 + 可选 RTS/CTS。

【2 分钟】 今天的内容一页回顾。 CSMA：先听后说；但别人开始发以后 τ 之内你还听不到，所以仍会碰撞。β 等于 τ 除以 T，决定一切：越小越好；太大时，侦听还不如时隙 ALOHA。 通过率：β = 0.01 时，非坚持 CSMA 0.815，时隙 CSMA 0.865，CSMA/CD 0.968，对比时隙 ALOHA 的 0.368。这些是理想模型的峰值。 稳定：伪贝叶斯换个目标，q 等于 √(2β) 除以 ñ，新分组也先进积压。 实践：经典以太网用 1-坚持 CSMA/CD 加二进制指数退避，只用于共享、半双工；Wi-Fi 用 CSMA/CA：随机退避、冻结与恢复、确认，必要时用 RTS/CTS。 下一讲 4.4，冲突分解：在不能侦听、或者 β 不小的场合，撞了以后，能不能有组织地把碰撞解开，突破时隙 ALOHA 的 1/e？
