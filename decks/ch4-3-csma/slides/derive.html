【5 分钟 · 推导请带着学生走一遍】 第一步，空闲期：泊松流里等下一次尝试，平均等 1/G。成功的概率：忙期开始后 β 之内没有别人开始。泊松流在长为 β 的区间里没有到达的概率，是 e 的负 βG 次方。 第二步，Y 的平均值。Y 大于 y，等价于在 y 到 β 之间还有人开始发，概率是 1 − e^(−G(β − y))。一个非负随机变量的平均值，等于它大于 y 的概率对 y 积分。从 0 积到 β，得到 β − (1 − e^(−βG))/G。β 趋于 0 时 E[Y] 趋于 0，Y 的范围也始终在 0 到 β 之间。 第三步，周期的平均长度：空闲期 1/G，加忙期 Y + 1 + β。把第二步代进去，其中负的 1/G 和正的 1/G 抵消，剩下 1 + 2β + e^(−βG)/G。 第四步，每个周期里，成功的概率是 e^(−βG)，成功时传送的有效时间是 1。所以通过率 S 等于 e^(−βG) 除以 1 + 2β + e^(−βG)/G。分子分母同乘 G，得到 S = G e^(−βG) / [G(1 + 2β) + e^(−βG)]。 说明：这个公式属于这个简化模型（所有节点用同一个有效盲区 β，现实拓扑里各处的传播时延并不相同），不要说成所有非坚持实现和拓扑下的精确公式。 [积分验算：∫ (1 − exp(−G(β − y))) dy 从 0 到 β = β − (1/G)(1 − exp(−βG))。]
