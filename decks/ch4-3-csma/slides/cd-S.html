【4 分钟】 用时隙 CSMA 同样的模型分析 CSMA/CD，唯一的变化：碰撞不再占 1 + β，只占大约 2β，β 用来发现碰撞，再一个 β 让信道空出来。 第一步，平均间隔：空闲的概率 e^(−g)，占 β；成功的概率 g e^(−g)，占 1 + β；碰撞的概率是 1 − (1 + g) e^(−g)，占 2β。合起来，平均间隔等于 β e^(−g) + (1 + β) g e^(−g) + 2β[1 − (1 + g) e^(−g)]。离开率等于成功概率除以平均间隔，倒过来整理，得 1/S = 1 + β (2 e^g − 1 − g)/g。注意这一步是精确的，没有近似，所以 S 的最大值恰好是 1/(1 + c β)，c 是括号那一项的最小值。 第二步，括号里那一项对 g 求导，令导数为 0，得 2 e^g (1 − g) = 1，解得 g ≈ 0.768。第三步，代回去，最小值约 3.31。所以 CSMA/CD 的最大通过率等于 1/(1 + 3.31 β)。 右边的数字：β = 0.01 时，CSMA/CD 是 0.968，时隙 CSMA 是 0.865；β = 0.05 时，0.858 对 0.719。为什么最佳的 g 从 0.14 变成了 0.77？因为碰撞便宜了，只浪费 2β，所以可以大胆一点，多尝试，少留空闲。 说明：这个模型和真实的以太网协议并不完全相同（忽略了 jam、帧间隙和退避的实现细节），所以这里的极值是模型的极值，不是实际以太网固定的效率，也不是有效载荷线速百分比的测量值。 [验算：g = 0.768 时 2e^g (1 − g) = 1.000，(2e^g − 1 − g)/g = 3.311。]
