稳定的时隙 CSMA：伪贝叶斯换个目标

用 α = √(2β) 作为小 β 时的目标尝试数，再估计当前积压，就能把总体目标换算成每个分组的发送概率。

【讲读提示】用 α = √(2β) 作为小 β 时的目标尝试数，再估计当前积压，就能把总体目标换算成每个分组的发送概率。 【4 分钟】 和上一讲一样，固定的 q 在节点无穷多时会出问题；办法也一样：用反馈估计积压数，动态调整 q。 目标换了：ALOHA 想让 G 约等于 1；时隙 CSMA 想让每个竞争机会的尝试数 g 约等于 √(2β)，也就是上一页的最佳点。所以新分组也立刻算作积压（注意这是接入规则的变化，和上一页基础模型里“新分组下次必发”不同），每个积压分组以 q = min(α/ñ, α) 发送，α = √(2β)。这样 ñ q 约等于 α。要求 α < 1，并用正数初始化估计。 估计的更新分三种情况。怎么理解？把积压数看成均值为 ñ 的泊松分布，每个分组以概率 q 发，没发的平均有 ñ(1 − q) 个。空闲：没人发，剩下的就是没发的这些，再加上这个小时隙 β 里新来的 λβ 个。成功：发的那一个走了，剩下的还是没发的这些，再加上 1 + β 这段时间里新来的。碰撞：至少两个人发了，它们没走，都还在，所以大约是 ñ 再加 2，再加新来的。这里的 +2 是条件信息引起的近似修正，不是碰撞凭空多出两个分组。 算一个例子：β = 0.01，λ = 0.5，α = 0.1414，初始 ñ = 2，依次观察空闲、碰撞、成功。第 1 步：q = 0.1414/2 = 0.0707，空闲，ñ = 2 × (1 − 0.0707) + 0.005 = 1.864。第 2 步：q = 0.0759，碰撞，ñ = 1.864 + 2 + 0.505 = 4.369。第 3 步：q = 0.0324，成功，ñ = 4.369 × (1 − 0.0324) + 0.505 = 4.732。成功以后估计也可能增大：较长的忙期里仍有新分组到达。 最妙的是：如果把 q 换成 1/ñ，ñ(1 − q) 恰好等于 ñ − 1，这正是 4.2 里空闲和成功时的“减 1”。两个算法是同一个思路：用贝叶斯的眼光看待反馈。 【收束提示】概率会随反馈变化，效果要放到持续到达的系统里看：成功是否跟得到达，等待是否越来越长？
