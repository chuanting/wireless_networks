实际网络里：OSPF 与 IS-IS

OSPF 与 IS-IS 把链路状态方法组织成可部署的协议。区域或层级减少每个节点必须保存的细节，但不能省掉可靠传播与重新计算。

OSPFv2

RFC 2328：路由器与网络 LSA 在区域内传播；外部 LSA 可跨区域，不能说所有洪泛都止于区域。普通自生成 LSA 每 1800 秒刷新，MaxAge 为 1 小时。

LAN

广播型网络使用 DR 与 BDR 协助邻接和状态同步；这是控制消息的组织方式，不是让所有数据都经过 DR。

IS-IS

同样传播链路状态并计算最短路径，以层级组织网络。比较协议时要看区域或层级、度量、同步和故障处理。

链路状态提供地图；可靠传播让地图足够新，稳定的度量与更新策略让路径不会频繁摆动。

传播最新信息是一项工作；根据负载改变代价后能否稳定，是另一项工作。这两个问题共同决定动态路由是否可靠。

【讲读提示】OSPF 与 IS-IS 把链路状态方法组织成可部署的协议。区域或层级减少每个节点必须保存的细节，但不能省掉可靠传播与重新计算。 【3 分钟】 OSPFv2 见 RFC 2328。Router-LSA 和 Network-LSA 的作用域为区域；AS-external-LSA 可以在 AS 范围传播，但不进入 stub 区域，所以“洪泛都只在区域内”过于绝对。LSRefreshTime 是 30 分钟，MaxAge 是 1 小时；年龄到上限还涉及协议规定的洪泛清除流程，不能与教材简化的剩余寿命直接等同。广播型 LAN 选 DR、BDR，其他路由器与两者建立邻接。IS-IS 也是链路状态协议，通过层级组织拓扑。参考：https://www.rfc-editor.org/rfc/rfc2328 ，7、12、14、附录 B。 【收束提示】传播最新信息是一项工作；根据负载改变代价后能否稳定，是另一项工作。这两个问题共同决定动态路由是否可靠。
