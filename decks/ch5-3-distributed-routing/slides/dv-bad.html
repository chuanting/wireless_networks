坏消息一轮只前进一点：节点反复拿对方的旧消息互相“喂”。

【3 分钟】 再看坏消息。还是这一行节点，原来已经稳定：B 到 A 是 1，C 是 2，D 是 3，E 是 4。现在 A 到 B 的链路断了。 B 马上发现自己直接到 A 的链路没有了。可是 C 刚刚告诉过它：“我到 A 只要 2”。B 不知道 C 的这个 2 是经过自己才有的，就以为 C 另有一条路，于是更新：B 到 A 是 1 + 2 = 3，下一跳是 C。 下一轮，C 听到 B 说“我到 A 是 3”，更新为 3 + 1 = 4。再下一轮，B 听到 C 说 4，更新为 5；C 变成 6……B 和 C 互相拿对方的旧消息喂对方，每两轮增加 2，一直增加下去，这就是“计数到无穷”。表里 D、E 也跟着一起涨。 什么时候停？必须给“无穷”定一个有限的数。RIP 把 16 当作无穷，也就是最大跳数 15 加 1；这个例子里从第 0 轮到所有节点都变成 16，需要 15 轮。如果距离的度量是时延，就很难定一个合适的上界：它要足够大，不能把长时延的路径当成断开的链路。 在这十几轮里，B 和 C 之间分组会来回打转，这正是 5.1 里的路由环路。 [程序按同步更新模拟，数字就是表里的。]
