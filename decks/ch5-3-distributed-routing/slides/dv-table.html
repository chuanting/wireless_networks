B、C 的向量是上一轮的，各自只知道自己的直接链路。A 把两个候选逐项取小：D 经 B 得 7，E 经 C 得 6；到 F 还没有路。下一轮 B、C 的向量里有了 F，A 得到 9。

每一轮，每个节点都做这样的一次“取小”。

【3 分钟】 用 5.1 的六台路由器的例子，看路由器 A 怎样更新。A 有两个邻居：B，链路长 2；C，链路长 4。 第 0 轮，每个节点只知道自己的直接链路：A 的向量里，B 是 2，C 是 4，D、E、F 都是无穷。B 的向量：A 2，C 3，D 5。C 的向量：A 4，B 3，E 2。 A 收到 B 和 C 的向量，各加上到它们的链路长度，得到两个候选：经 B，2 加 B 的向量：B 2，C 5，D 7，E 无穷，F 无穷；经 C，4 加 C 的向量：B 7，C 4，D 无穷，E 6，F 无穷。对每个目的地，在旧值和两个候选里取小：B 是 2，下一跳 B；C 是 4，直接走 C（经 B 是 5，更长）；D 是 7，经 B；E 是 6，经 C；F 仍然是无穷。表里蓝色的是这一轮新得到的值。 下一轮，B 的向量里有了 F（经 D，7），C 的向量里有了 F（经 E，8），A 经 B 得到 9。所以两轮之后，A 的向量已经和 5.2 的最短距离一样：B 2，C 4，D 7，E 6，F 9。 其他节点同时在做同样的事。六台路由器一共 16 条消息一轮，每条 6 项。2 轮以后，所有节点的向量不再变化。 [程序模拟了全网的同步更新，并与最短路径逐项核对。]
