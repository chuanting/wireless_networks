练习（一）：向量更新、计数到无穷与序号

①

用本讲的网络：C 的邻居 A、B、E，链路 C–A 4，C–B 3，C–E 2。第 0 轮 A、B、E 的向量（到 A、B、C、D、E、F）分别是 (0, 2, 4, ∞, ∞, ∞)、(2, 0, 3, 5, ∞, ∞)、(∞, ∞, 2, 3, 0, 6)。求 C 的新向量和下一跳。

②

一行五个节点 A–B–C–D–E，链路长度都是 1，目的地 A，A–B 断了，RIP 的“无穷”是 16。B 的值依次是多少？几轮后所有节点都到 16？

③

B 已存有 E 的 5 号分组。又依次收到 E 的 4 号、再一份 5 号（从另一个邻居）、6 号：各怎样处理？

【4 分钟 · 参考答案】 ① 经 A：4 加 A 的向量 = (4, 6, 0, ∞, ∞, ∞)；经 B：3 加 B 的向量 = (5, 3, 0, 8, ∞, ∞)；经 E：2 加 E 的向量 = (∞, ∞, 0, 5, 2, 8)。逐项取小：到 A 是 4（下一跳 A），到 B 是 3（B），到 D 是 5（E），到 E 是 2（E），到 F 是 8（E）。和 DV 第 1 轮 C 的向量一致。 ② 没有水平分割：B 的值依次是 1, 3, 3, 5, 5, 7, 7, 9, 9, 11……：每两轮增加 2；所有节点都到 16 需要 15 轮。 ③ 4 号：比存的 5 小，是过时的，丢弃。第二份 5 号：序号相同，是重复的，不再转发给送来的邻居，只确认。6 号：比存的大，替换，转发给除来路以外的邻居并确认。 [验算：①② 程序同步模拟，③ 按包缓冲区的规则。]
