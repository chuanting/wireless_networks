割性质

无论怎么把点分成两部分，跨越两部分的边里最便宜的那条，一定在最小生成树里。

例：S = {A, B, D}。跨越的边有 BC 6、BE 3、DE 9，最便宜的 BE = 3 果然在树里。

三种算法，其实都在选这样的边

Prim：S = 已连通区域

Kruskal：S = 这条边一端所在的团体

分布式：S = 一个团体，出口边就是跨越边

【1.5 分钟 · 本课的“揭晓”】 终于可以回答第 3 部分留下的问题：为什么三种做法完全不同，却都得到最小生成树？因为它们都在用同一条性质——割性质： 把点任意分成两部分 S 和 V−S，跨越两部分的所有边里，最便宜的那一条，一定在最小生成树里（造价互不相同时）。 例：S = {A,B,D}，跨越的边是 BC 6、BE 3、DE 9，最便宜的 BE = 3，确实在最小生成树里（回忆：最小生成树是 AD、AB、BE、EF、BC）。 三种算法对应三种“分法”： Prim：每一步，S = 已连通区域，选的边是跨越区域边界最便宜的那条 ✓。 Kruskal：每选一条边 uv，取 S = u 所在的团体，则 uv 就是跨越 S 的最便宜的边（比它更便宜的边早已检查过：如果它跨越 S，早就被选上了，u 所在的团体就会更大，矛盾）。 分布式：S = 一个团体，它的出口边就是跨越边，选最便宜的 ✓。 所以不管怎么贪心，只要每一步选的都是“某个割里最便宜的边”，就不会出错。 下一页用一个数字例子说明为什么割性质成立（可选，时间紧可以跳过）。
