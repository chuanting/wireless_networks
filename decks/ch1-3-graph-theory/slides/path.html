路径：一串点，相邻两点之间有边，点不重复。例：A → B → E → F，经过 3 条边，长度是 3；带权图里长度是边权之和：4 + 3 + 1 = 8。

回路：起点和终点是同一个点，其余点不重复。例：A → B → D → A。

回路是备份线路：AB 断了还能绕 A → D → B，但每条备份线都要花钱。最小生成树不含回路。

【3 分钟】 路径：一串点，相邻两点之间有边，而且点不重复。例：图书馆 → 教学楼 → 实验楼 → 体育馆，即 A → B → E → F，经过 3 条边，长度是 3；在带权图里，路径长度等于经过的边权之和，4 + 3 + 1 = 8 万元。导航软件找的“最短路径”，就是长度最小的路径。A 到 F 还有别的路径：A-D-E-F、A-B-C-F……可以有很多条。 回路：起点和终点是同一个点，其余点不重复。例：A → B → D → A。回路就是备份线路：AB 这条线断了，还能绕 A → D → B 通信；但每条备份线都要花钱，所以最小生成树里不含回路。 严格地说，这里的路径是“简单路径”；点可以重复经过的叫“游走”。
