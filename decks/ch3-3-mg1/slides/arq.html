【4 分钟】 重传是服务时间波动的一个典型来源。简化模型：一个分组第一次发送占 1 个时间单位；如果出错（概率 p），要等确认超时再重发，重发一次多占 n 个时间单位；重发还可能再错，所以重发次数 K 是几何分布，P(K = k) = p^k (1−p)，平均 E[K] = p/(1−p)，E[K^2] = p(1+p)/(1−p)^2。服务时间 X = 1 + nK。 取 p = 0.1，n = 6。E[K] = 1/9，E[K^2] = 0.1358。E[X] = 1 + 6/9 = 1.667；E[X^2] = 1 + 2×6×(1/9) + 36×0.1358 = 7.222。 到达率 λ = 0.5。没有错误时，X = 1 固定，ρ = 0.5，W = 0.5，T = 1.5。有 10% 的出错率时，ρ = 0.5 × 1.667 = 0.833，W = 0.5 × 7.222/(2 × (1 − 0.833)) = 10.83，T = 12.5。出错率只有 10%，等待却变成 20 多倍。原因有两个：负荷从 0.5 涨到 0.83；服务时间的波动也大了（二阶矩从 1 变成 7.2）。 [说明：这是简化模型，每次重发都多占 n 个时间单位，不是精确的 Go-Back-N 或选择重传，只用来说明服务时间的波动怎样放大等待。事件模拟 400 万个分组：10.88，公式 10.83。]
