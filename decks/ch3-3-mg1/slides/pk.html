【3 分钟 · 重点】 把 R = λE[X^2]/2 代进 W = R/(1−ρ)，就得到 Pollaczek–Khinchin 公式，简称 P-K 公式：W = λE[X^2]/[2(1−ρ)]。 得到 W 以后，一切都顺理成章：系统时延 T 等于等待加上自己的服务，T = E[X] + W；队列里的平均人数 N_Q = λW；系统里的平均人数 N = λT，这都是 Little 定理。 条件：到达是泊松，服务时间独立同分布，ρ = λE[X] < 1，而且二阶矩 E[X^2] 必须是有限的。如果服务时间的尾巴太重（比如某些重尾分布），二阶矩无穷，平均等待就是无穷，哪怕 ρ < 1。 这个公式是整个 3.3 节的主角：休假、复用、轮询、优先级，后面都在 P-K 公式上加一项或改一项。 [提示：平均等待由 λ、E[X]、E[X^2] 三个数决定。]
