多等半个休假？只对固定休假成立

M/D/1，λ = 0.5，服务时间 X = 1；休假的平均长度都是 2。

没有休假

0.5

固定休假 2

1.5

指数休假，平均 2

2.5

固定休假多等 2/2 = 1；指数休假的二阶矩是 8，多等 8/4 = 2。单位：服务时间。

休假的平均长度相同，长短越不齐，等得越久。

【3 分钟】 数字例子：M/D/1，λ = 0.5，X = 1，没有休假时 ρ = 0.5，W = 0.5 × 1/(2 × 0.5) = 0.5。 加上固定休假 V = 2：E[V^2] = 4，额外一项 E[V^2]/(2E[V]) = 4/4 = 1，W = 1.5，T = 2.5。这就是“多等半个休假”。 如果休假长度是随机的，平均仍是 2，比如指数分布：E[V^2] = 2 × 2^2 = 8，额外一项 8/4 = 2，W = 2.5，T = 3.5。多等的不是“半个平均休假”，而是 E[V]/2 + Var[V]/(2E[V]) = 1 + 4/4 = 2。所以“半个休假”的说法只对固定休假成立。 [验算：事件模拟 150 万个分组，固定休假 W = 1.50，指数休假 W = 2.50，与公式相差在 1% 以内。]
