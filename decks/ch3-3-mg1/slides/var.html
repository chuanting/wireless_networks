【4 分钟】 P-K 公式还可以写成另一种形式。把二阶矩写成 (1 + C^2) 乘以平均值的平方，并用 ρ = λE[X]，得到 W = (1 + C^2)/2 · ρ/(1−ρ) · E[X]。在 λ 和 E[X] 固定的前提下，等待随 C^2 线性增长：C^2 = 0 是 M/D/1，C^2 = 1 是 M/M/1，C^2 再大，就比 M/M/1 还要差。 看一个现实的例子。链路速率 10 Mb/s，数据分组 1500 字节，发送要 1.2 ms；确认分组 40 字节，发送只要 0.032 ms。假设 90% 是短分组，10% 是长分组：平均服务时间 E[X] = 0.9 × 0.032 + 0.1 × 1.2 = 0.1488 ms，二阶矩 E[X^2] = 0.9 × 0.032^2 + 0.1 × 1.2^2 = 0.1449216 ms^2，C^2 = E[X^2]/E[X]^2 − 1 = 5.55，约 5.5。 取负荷 ρ = 0.8，到达率 λ = 0.8/0.1488 = 5.38 个/ms。如果所有分组都一样长（E[X] 仍是 0.1488 ms），平均等待 0.298 ms；指数分布 0.595 ms；真实的混合分布是 1.948 ms，是等长情形的 6.5 倍。 结论：评估链路时延，不能只用平均包长；包长分布的波动同样重要。 [验算：事件模拟 300 万个分组，混合分布平均等待 1.946 ms，与公式相差 0.1%。]
