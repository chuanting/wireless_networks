【3 分钟】 M/G/1：第一个 M，到达仍然是泊松过程；G 是 General，服务时间是任意分布；1 个服务员。假设每个顾客的服务时间独立同分布，和到达过程无关；先来先服务，缓冲区无限。 对服务时间，我们需要知道两个数：平均值 E[X]，也就是 1/μ；二阶矩 E[X 平方]。ρ 仍然等于 λ 乘 E[X]，必须小于 1。二阶矩和平均值、方差的关系是：方差等于二阶矩减去平均值的平方。我们再定义一个“波动系数” C 平方，等于方差除以平均值的平方：它度量服务时间的波动有多大。 看表里几种分布。设平均值都是 1/μ。确定值：每个顾客服务时间完全相同，没有波动，二阶矩是 1/μ 的平方，C 平方等于 0。均匀分布，在 0 到 2/μ 之间：二阶矩 4/(3μ 的平方)，C 平方是 1/3。指数分布：二阶矩是 2/μ 的平方，C 平方等于 1。最后一行是后面要用的例子：90% 的短包加上 10% 的长包，C 平方高达 5.5。 关键点：平均值相同，但二阶矩可以差很多。下一页开始看它怎么影响时延。 [验算：均匀分布方差 (2/μ)²/12 = 1/(3μ²)；二阶矩 = 方差 + 均值² = 4/(3μ²)。]
