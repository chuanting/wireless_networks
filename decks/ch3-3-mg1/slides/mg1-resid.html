第一部分 · M/G/1

推导（二）：平均剩余服务时间 R = λ E[X²] / 2

剩余服务时间 r(t)：锯齿

X1 = 2

X2 = 1

X3 = 3

三个三角形的面积分别是 X 的平方 / 2

面积 = 2 + 0.5 + 4.5 = 7；观察 10 秒：R = 7 / 10 = 0.7

每次服务

开始时，剩余时间跳到 X，然后均匀下降到 0：一个直角三角形，面积 X 的平方 / 2。

时间平均

R = (1/t) × 所有三角形面积之和 = (1/2) · [服务次数 / t] · [ΣX 的平方 / 服务次数]

极限

R = (1/2) λ E[X 的平方]

数字核对：λ = 3/10，E[X 的平方] = (4+1+9)/3 = 4.67；(1/2) × 0.3 × 4.67 = 0.7 ✓。

【4 分钟 · 重点】 这一页求平均剩余服务时间 R。看图：横轴是时间，纵轴是“正在服务的那个顾客，还剩多少服务时间”，叫 r(t)。 每次服务开始的瞬间，r 跳到这个顾客的服务时间 X；然后随着服务进行，匀速下降，到 0 服务完成。服务员空闲时，r 等于 0。图里有三次服务，服务时间分别是 2、1、3，所以是三个直角三角形，底和高都是 X，面积是 X 的平方除以 2。 r(t) 的时间平均，就是所有三角形的总面积，除以总时间 t。把它拆成两个因子：服务次数除以 t，就是单位时间服务的顾客数；再乘上每次服务的 X 平方的平均，除以 2。当 t 趋于无穷，服务次数除以 t，等于到达率 λ；X 平方的平均，是二阶矩 E[X 平方]。所以平均剩余服务时间 R，等于二分之一乘 λ 乘 E[X 平方]。 用图里的数字核对：10 秒里服务 3 个顾客，λ 等于 0.3，二阶矩 E[X 平方]，等于 (4 加 1 加 9) 除以 3，约 4.67。二分之一乘 0.3 乘 4.67 等于 0.7。直接数面积：2 加 0.5 加 4.5 等于 7，除以 10，也是 0.7。完全吻合。 [验算：面积 = 2²/2 + 1²/2 + 3²/2 = 2 + 0.5 + 4.5 = 7。]
