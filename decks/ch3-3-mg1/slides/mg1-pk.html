P-K 公式

P-K（Pollaczek–Khinchin）公式

把 R = (1/2) λE[X 的平方] 代入 W = R / (1 − ρ)：

W = λE[X²] / [2(1 − ρ)]

平均时延：T = E[X] + W

队列平均长度：NQ = λW；系统平均：N = λT

只要知道 λ、平均 E[X] 和二阶矩 E[X 的平方]，就能算出时延。

特例 1：M/M/1

E[X 的平方] = 2/μ 的平方：W = λ · 2/μ 的平方 / [2(1−ρ)] = ρ / (μ − λ) ✓

特例 2：M/D/1

E[X 的平方] = 1/μ 的平方：W = ρ / [2(μ − λ)]：恰好是 M/M/1 的一半。

写成 C² 的形式

W = (1 + C²)/2 · [ρ/(1 − ρ)] · E[X]。波动越大，等得越久。

【4 分钟 · 重点】 把 R 的结果代回去：W 等于 R 除以 (1 − ρ)，R 等于 λ 乘 E[X 平方] 除以 2。得到： W 等于 λ 乘 E[X 平方]，除以 2 倍的 (1 − ρ)。 这就是著名的 P-K 公式，Pollaczek 和 Khinchin 在 1930 年代得到的。有了 W，平均时延 T 等于平均服务时间加平均等待；队列的平均长度 N_Q 等于 λW；系统里的平均人数 N 等于 λT。 重要的是：只要知道到达率 λ、服务时间的平均值和二阶矩，就能算出时延。不需要知道服务时间的完整分布。 检验：服务时间是指数分布时，二阶矩是 2/μ 的平方，代入：W 等于 λ 乘 2/μ 的平方，除以 2(1 − ρ)，化简就是 ρ 除以 (μ 减 λ)——和 M/M/1 的结果一样。 特例二：服务时间是固定值，M/D/1。二阶矩只有 1/μ 的平方，是指数分布的一半，所以等待时间恰好是 M/M/1 的一半！ 更一般地，可以把二阶矩换成“波动系数” C 平方：W 等于 (1 加 C 平方) 除以 2，乘以 ρ 除以 (1 减 ρ)，再乘以 E[X]。C 平方等于 0（固定），系数是 1/2；C 平方等于 1（指数），系数是 1；C 平方越大，等待越久。 [提示：这是本节最重要的公式，建议学生抄下来。]
