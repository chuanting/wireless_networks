第二部分 · 排队系统

同样的平均速率，为什么随机到达就会排队？

均匀到达：每 2 秒来 1 个（服务 1 秒）

8 个顾客的平均等待 = 0 秒。

随机到达：16 秒内也来 8 个（平均每 2 秒 1 个）

8 个顾客的平均等待 = (0 + 0.5 + 1 + 0 + 0.5 + 0 + 0 + 0.5) / 8 ≈ 0.31 秒。

图例

▼ 顾客到达；蓝条 = 服务；橙条 = 等待。横轴单位：秒。

两种情形

都是 λ = 0.5 个/秒，μ = 1 个/秒，ρ = 0.5。

原因

随机到达会“扎堆”：0 到 1 秒来了 3 个，后两个必须等。

排队的根源不是“忙”，而是“不均匀”。

【3 分钟 · 可压缩】 用一个小例子，看排队是怎么产生的。服务员每个顾客服务 1 秒。 上面一行：顾客均匀到达，每 2 秒来一个，8 个顾客一共 16 秒。每个顾客到的时候，服务员都是空闲的，没有人需要等，平均等待是 0 秒。服务员一半的时间在忙，一半的时间闲着，ρ 等于 0.5。 下面一行：同样是 16 秒内来 8 个顾客，平均每 2 秒一个，ρ 也是 0.5，但是到达是随机的，会“扎堆”。看开头：0 秒、0.5 秒、1 秒，3 个顾客几乎同时来了。第一个直接服务；第二个到的时候，第一个还没服务完，要等 0.5 秒；第三个要等 1 秒。后面 5 秒、5.5 秒又扎了一次堆，第二个要等 0.5 秒。最后 12.5 秒和 13 秒，第二个等 0.5 秒。把 8 个顾客的等待加起来，2.5 秒，平均 0.31 秒。 同样的平均速率，同样的利用率，均匀到达没有等待，随机到达就有了等待。 所以排队的根源，不是“忙”，而是“不均匀”。只要到达是随机的，即使服务员有一半时间闲着，也会有人等。这就是为什么后面需要概率论、需要泊松过程。 [验算：用 Python 复算过：等待依次为 0、0.5、1、0、0.5、0、0、0.5，平均 0.3125 秒。]
