没离开的人：t 时刻还没走的顾客，停留时间只算了一部分；t 很大时，这点误差占的比例趋于 0。

到达率 = 离开率：稳定时队列不会无限增长，进来多少，就走多少。

代入上一页的数据：N = 7/5 = 1.4，λT = 3/5 × 7/3 = 1.4。

【4 分钟 · 重点】 把面积相等写成公式，再变成 Little 定理。 第一步：到 t 时刻为止，面积的两种算法，得到：N(τ) 从 0 到 t 积分，等于前 α(t) 位顾客的停留时间之和。 第二步：两边除以 t；右边再乘上 α(t)、除以 α(t)，乘除同一个数，值不变。就得到：左边是 N 的时间平均；右边是两个括号的乘积：第一个，α(t) 除以 t，是单位时间到达的顾客数，也就是到达率 λ；第二个，所有停留时间之和除以顾客数，是平均停留时间 T。 第三步：令 t 趋于无穷，三项都有极限，就得到 N 等于 λ 乘 T。 右边三个提醒。一，到 t 时刻还没离开的顾客，停留时间只算了一部分，所以“前 α(t) 位顾客的停留时间之和”并不严格等于面积；t 很大时，这个误差占的比例趋于零。二，这里用的是“到达率”；稳定时，到达率等于离开率，因为队列不会无限增长。三，整个证明里，没有用到到达的分布、服务的分布，也没有用到服务顺序。 代入上一页的数据检验：N 等于 7 除以 5，等于 1.4；λ 是 3 除以 5，T 是 7 除以 3，乘起来也是 1.4。（这个例子里观察结束时系统恰好是空的，所以有限时间内也精确成立；一般情形是 t 趋于无穷时成立。） [说明：严格的版本需要长期平均存在，并且边界项相对观察时间趋于零。]
