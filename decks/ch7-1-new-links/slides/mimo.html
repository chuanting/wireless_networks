平坦瑞利衰落，总发射功率不变，接收端知道信道，信噪比 10 dB。代价：要测出 n 乘 n 的信道，射频和计算量都随 n 增加。

【4 分钟】 再看第三个旋钮：天线。表里是 n 根发射天线、n 根接收天线、信道是独立的瑞利衰落时的平均容量，总发射功率不变。 n = 1：2.90 比特每秒每赫兹；n = 2：5.55，是 1.92 倍；n = 4：10.95，3.78 倍；n = 8：21.81，7.53 倍。基本上和天线数成正比。最后一行是作对比：单天线、功率加倍，只多了 29%，而天线加倍多了 92%。 道理：n 乘 n 的信道矩阵，有 n 个独立的通道，可以同时传 n 路数据，这叫空间复用。如果这 n 路数据给 n 个不同的用户，就是空分多址：同一时间、同一频率，不同方向上的用户互不干扰。这是 1.4 讲的第三个问题（多址）的一个新维度，之前 4.1 讲的是频率、时间、码字。 代价也要说清楚：发射端要知道信道才能把波束对准，所以要发导频测信道，信道变得快（高速移动、频率高）时，测量的开销就大；n 越大，射频通道和矩阵运算越多。所以天线数不是越多越好。 [20000 次随机信道的平均；n = 1 的值用另一种方法核对：对指数分布的信噪比积分，两者相差不到 1%。]
