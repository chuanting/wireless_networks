Bellman–Ford 为什么对

①

h = 1：最多一条链路的最短行走，就是直接链路。显然。

②

假设 D(i, h) 是最多 h 条链路的最短行走。最多 h + 1 条链路的最短行走，要么链路数 ≤ h，长度 D(i, h)；要么恰好 h + 1 条，长度 d(i, j) + D(j, h)。

③

取较小者。由归纳，D(j, h) 不会比 D(j, h − 1) 大，所以后者不大于 D(i, h)，较小者就是：

④

终止：如果不经过目的地的环长度都 ≥ 0，绕环不会变短，最短行走可以取成路径，至多 N − 1 条链路；所以至多 N − 1 轮后不再变。

归纳法：先证 h = 1，再从 h 推到 h + 1。

关键：最短行走的第一条链路是 (i, j)，余下的部分本身是 j 的最短行走。

反过来：如果有长度为负的环，绕一圈就更短，永远不会停（下一页）。

没有负长度的环，Bellman–Ford 至多 N − 1 轮就停。

【4 分钟 · 推导请带着学生走一遍】 下面证明两件事：每一轮算出来的 D(i, h) 确实是“最多 h 条链路”的最短行走；以及什么时候停。 第一步，h = 1：最多一条链路，要么直接有链路，长度 d(i, 目的地)，要么没有，无穷大。这显然就是递推式给的结果。 第二步，假设 D(i, h) 对所有 i 都已经成立。看最多 h + 1 条链路的最短行走。它的链路数要么不超过 h，这时长度就是 D(i, h)；要么恰好 h + 1 条，这时它的第一条链路是某个 (i, j)，余下的部分是从 j 出发恰好 h 条链路的行走，最短的就是 D(j, h)，长度是 d(i, j) + D(j, h)。 第三步，两种取小。再用一个归纳的事实：D(j, h) 不会比 D(j, h − 1) 大（允许走更多链路，只会更短或相等）。所以 min over j 的 d(i, j) + D(j, h) ≤ min over j 的 d(i, j) + D(j, h − 1) = D(i, h)，也就是第二种情况总不大于第一种，两者取小就等于第二种：这正是递推式。 第四步，终止。设所有不经过目的地的环的长度都不小于 0。那么最短行走里的环可以删掉而不增加长度，所以最短行走可以取成路径，路径最多 N − 1 条链路。所以到 h = N − 1 以后，再多允许走也不会更短：算法至多 N − 1 轮就停。 反过来，如果存在长度为负的环，在这个环上多绕一圈就更短，每多允许走几条链路，D 就继续减小，永远不会停。下一页举例。
