一轮扫多少条边，最坏要扫几轮？

先数六路由器图

图里有 6 个点、8 条双向链路。一次扫描把 8 条链路的两个方向都试一遍，共 16 次候选比较。

推广到 N 个点、L 条边

每轮的工作量与 L 成正比，最多 N−1 轮就覆盖无重复节点的路线，还可加一轮检测负环。最坏时间为 O(NL)。

为什么要规定初值和更新顺序？

源点或目的地记 0，其余记 ∞。同步版本读上一轮；若边算边改，仍须让每条需要更新的边得到机会，轮号也失去了原来的段数含义。

边很密时，L 可与 N 的平方同阶，此时 O(NL) 才达到 N 的三次方量级。

【2 分钟】在六节点图上，最多五轮覆盖所有简单路线，本例第三轮得到最终值，第四轮用来确认。双向链路分两次检查只影响常数倍。标准初始化为可行路线的上界。向学生提出反例：A 和 B 以 0 相连，各自到终点要 1，若错误地把两者初始化为 0，只做降低操作就无法纠正。固定拓扑、无相关负环且采用公平的异步松弛可收敛。协议收到旧消息或链路失效时还需要允许距离增大，属于 5.3 的内容。
