【4 分钟 · 点击核对】 在黑板左边留下第一轮 A=0、B=6、C=2、D=∞，右边用另一种颜色写第二轮。先把 C 的旧数 2 接上 C 到 B 的那条边，算出 3，比 B 原值 6 小，因此在右边写 B=3。 现在请学生为 D 报两个候选值，并说出每个数来自哪段路。A 到 B 再到 D 是 6+2=8；A 到 C 再到 D 是 2+8=10。所以第二轮末 D 得到 8。若学生报 5，请他指出那条路线经过几段，再点击核对。用 B 的新值 3 意味着已经先走了 A、C、B 两段，再接到 D 就成了三段。 为什么每轮只从旧记录出发？这样我们能准确说清楚搜索范围：上一轮最多一段，接一条边最多两段；本轮也保留原有的零段和一段路线。A=0、C=2 仍然保留。按这个同步版本，所有点都算完才把新记录交给下一轮。
