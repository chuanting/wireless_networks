【讲读提示】把 F 的距离始终固定为 0。读表时，每一格都问：第一跳交给哪个邻居，再加上该邻居上一轮报告的多少？ 【3 分钟】 同一个六台路由器的网络，目的地 F。表的每一行是一个 h，每一列是一个节点。蓝色加粗的数，是这一轮变小的。 h = 0：除了 F 都是无穷大。 h = 1：每个节点问邻居。D 的邻居里有 F，d(D, F) + 0 = 2；E 的邻居里有 F，6。其他节点的邻居此时都还是无穷大，所以没有值。 h = 2：B 问邻居：经 D 是 5 + 2 = 7；C 问邻居：经 E 是 2 + 6 = 8；E 现在可以问到 D 了，3 + 2 = 5，比原来的 6 小。A 的邻居 B、C 在上一轮还是无穷大，所以 A 还没有值。 h = 3：A 问邻居：经 B 是 2 + 7 = 9，经 C 是 4 + 8 = 12，取 9；C 问邻居：经 E 现在是 2 + 5 = 7，比 8 小。 h = 4：所有节点都没有变化，停。所以 3 轮就够了，而 N − 1 = 5 是最坏的上界。 最后一行就是各节点到 F 的最短距离：A 9，B 7，C 7，D 2，E 5。 [表由程序按递推式算出，并和穷举核对。] 【收束提示】h = 3 已得到正确值，h = 4 用来确认没有变化。距离稳定以后，还要把取得最小值的邻居记成下一跳。
