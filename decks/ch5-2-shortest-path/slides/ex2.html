练习（二）：运算量、矩阵与负环

④

N = 1000。求到一个目的地的最短路径：Bellman–Ford 与 Dijkstra（简单实现）的运算量各约多少？求所有节点对：Floyd–Warshall 呢？对每个目的地各跑一遍 Dijkstra 呢？

⑤

Floyd–Warshall：D(0) 的各行依次是 [0, 2, ∞]、[∞, 0, −1]、[4, ∞, 0]。写出允许节点 1 作中间节点后的 D(1)，以及最后的 D(3)。

⑥

有向图 1→2 长 3，2→3 长 −5，3→1 长 1。有负环吗？Floyd–Warshall 算完以后，对角线是什么？

【4 分钟 · 参考答案】 ④ Bellman–Ford：N 的三次方，约 10^9 次；Dijkstra：N 的平方，约 10^6 次。所有节点对：Floyd–Warshall 是 N 的三次方，约 10^9 次；对 1000 个目的地各跑一遍 Dijkstra，是 1000 × 10^6 = 10^9 次，量级一样。 ⑤ D(1) 里只有 3 到 2 变了：4 + 2 = 6：D(1) = 各行 [0, 2, ∞]、[∞, 0, −1]、[4, 6, 0]。最后 D(3) = 各行 [0, 2, 1]、[3, 0, −1]、[4, 6, 0]：1 到 3 是 2 + (−1) = 1，2 到 1 是 −1 + 4 = 3。 ⑥ 环 1→2→3→1 的长度是 3 − 5 + 1 = −1 < 0：有负环。算完后对角线都是负数：[-1, -1, -2]。D(3, 3) 在允许节点 1、2 作中间节点以后，就已经是 -1。 [验算：程序按三重循环计算。]
