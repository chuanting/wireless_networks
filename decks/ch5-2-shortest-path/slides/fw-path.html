第 i 行的“下一跳”列，就是路由器 i 的路由表。

【2 分钟】 有了每对节点的最短距离，还要得到路由表：下一跳。办法是在算距离的同时，记下“下一跳”。 再开一个矩阵 N(i, j)：从 i 去 j，第一步走向哪个节点。初始时，如果 i 到 j 有直接链路，N(i, j) = j。每当 D(i, j) 因为经过 n + 1 而变小，就把 N(i, j) 改成 N(i, n + 1)：到 j 的路改成先去 n + 1，所以第一步就是去 n + 1 的第一步。 看右边这个矩阵。查 1 到 2：N(1, 2) = 3，说明节点 1 去 2 先走到 3；N(3, 2) = 4，3 去 2 先走到 4；N(4, 2) = 2，直接到 2。路径 1、3、4、2，长度 3 + 4 − 1 = 6，和距离矩阵一致。 矩阵的第 i 行，每个目的地 j 的“下一跳”N(i, j)，就是路由器 i 的路由表。 另外，如果网络里有负环，Floyd–Warshall 算完以后，D(i, i) 会出现负数，这是检测负环的办法。
