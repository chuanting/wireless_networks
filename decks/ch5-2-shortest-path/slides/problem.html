【3 分钟】 先请同学沿两张图的粗线用手指各走一遍，说出两条路用了几段、总代价分别是多少。这里的代价是管理员设定的数，每经过一段就加一次。两张图的连线完全相同，粗线只标出正在检查的走法。 现在给十秒钟，让学生把中间的竖线用上。有人会得到 A → C → B → D，代价 2+1+2=5。也有人会沿相反方向穿过中线，得到 6+1+8=15。两条都是合法路线。先不投出答案，问学生：图再大一些，有什么办法系统地找到便宜的那条？接下来先学一种每次只多考虑一段的办法。
