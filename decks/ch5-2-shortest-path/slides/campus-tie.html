把 B–C 的代价记作 x，取非负数。沿 A → C → B → D 手指数一遍，全程要花多少？

与 A → B → D 比较。什么时候选 C 更省？什么时候选 B 更省？两边打平时，A 能写哪个下一跳？

经 C 再到 B 的代价是 4 + x，直接经 B 是 8。x 小于 4 时选 C，大于 4 时选 B，等于 4 时两条路同为最短。

【选做 · 3 分钟】 让学生先自己在图上改数字，试 1、4、5，再写等式。中间链路的代价是 x 时，A、C、B、D 为 2+x+2，A、B、D 一直是 8。A、C、D 一直是 10，另一条简单路径 A、B、C、D 为 14+x；在 x 非负时这两条都不会比 8 小。 在 x=4 时两个下一跳都能实现总代价 8；若这行表只填一个，写 B 或 C 均可。接下来的五节点练习换回固定目的地。让学生先把今天这道题里的“改价后从头重算”和“两个下一跳同时可选”用自己的话各说一遍。
