上面每轮用上一轮的记录接一条边，先找到 A → B → D。下面先确定距离为 2 的 C，从 C 找到 A → C → D。

中途的数字取决于先检查了哪些路线。两种方法最后都找到 A → C → B → D，代价 5，第一跳是 C。

【3 分钟】 先遮住最后一列。问同学：8 对应哪条真的能走的路？是哪两段相加？让另一位同学解释 10。两人都正确，算法当时可以使用的信息不同。再出示最后一列，让学生沿地图用手指走 2、1、2 三段。 如果有人说 Dijkstra 得到 10 那刻就算完了，请让他指出当时 B 还有哪个暂定数字。若有人说同步更新可以在第二轮直接填 5，请让他数一数这条路线的三段，并说出第二轮能使用的是 B 的哪一次记录。
