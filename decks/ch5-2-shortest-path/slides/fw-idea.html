【3 分钟】 Floyd–Warshall 一次求所有节点对的最短路径。想法是：一个一个地允许节点作“中间节点”。 定义：只允许节点 1 到 n 作为中间节点时，i 到 j 的最短长度，记作 D(i, j; n)。最开始 n = 0，没有中间节点，只能直接走链路：D(i, j; 0) = d(i, j)，没有链路的是无穷大，自己到自己是 0。 现在允许再多一个节点 n + 1 作中间节点。i 到 j 的最短路径有两种可能：没有用到 n + 1，那还是原来的 D(i, j; n)；用到了 n + 1，那它必定分成两段：i 到 n + 1，和 n + 1 到 j，这两段里都不再出现 n + 1，所以可以各取只用 1 到 n 作中间节点的最短长度，相加。取较小者。就是图下面的公式。 把 n 从 0 做到 N − 1，最后每一对节点的 D 就是允许所有节点作中间节点的最短长度，也就是真正的最短距离。三重循环：n 在最外层，i 和 j 在里面；运算量是 N 的三次方。 和 Bellman–Ford、Dijkstra 比：它们各求到一个目的地，Floyd–Warshall 一次求所有节点对，而且允许长度为负（但不能有负环）。
