圆旁是到 F 还要付的代价，线上是走这一段的代价。

经 B 去 F　2 + 7 = 9

经 C 去 F　4 + 7 = 11

第一跳只有这两种可能。每台路由器都比较“到邻居的代价 + 邻居到 F 的最短距离”。

D(i) = min

j ∈ N(i)

 [ c(i, j) + D(j) ]

这就是贝尔曼方程。N(i) 是 i 的邻居集合，c(i, j) 是链路代价，D(F) = 0。

每台路由器圈出取到最小值的邻居，就得到图上的箭头。A 查表交给 B，B 交给 D，D 交给 F。

【3 分钟】 让同学扮演 A，先给他 B 和 C 各自到 F 的距离 7。问应该比较哪两个数。把第一段也加进去，得到 9 和 11，再只记下便宜的下一跳 B。 公式里的 i 是正要做决定的路由器，j 把它所有邻居逐个取遍，适用于 i 与 F 不同、可以到达 F 的点。D(i) 是最短距离。若经 j 的后半程还有更短走法，整条路线也能缩短，因此只需比较每个邻居给出的最佳后半程。校园例比较进图书馆的最后一段，这个固定目的地的例子改为比较出发的第一段。 请学生从 C 顺箭头复核 C、E、D、F，合计 2 + 3 + 2 = 7。全图的箭头汇成以 F 为根的最短路径树，这是 5.3 路由器要写进转发表的下一跳信息。
