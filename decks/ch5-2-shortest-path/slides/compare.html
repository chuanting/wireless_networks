【讲读提示】比较复杂度必须使用相同的任务和实现。表中 N 是节点数、L 是链路数；Dijkstra 使用扫描找最小值的简单实现。 【3 分钟】 Bellman–Ford 每轮扩展边数，Dijkstra 扩展永久集合，Floyd–Warshall 扩展允许的中间节点。BF 与 Dijkstra 一次解决一个源或一个目的；FW 一次解决所有节点对。BF 和 FW 允许负边，并能检测相关负环；有负环影响的节点对没有有限答案。BF 的一般界是 O(NL)，只有稠密图才成为 N 的三次方量级。Dijkstra 此表为简单扫描版 N 的平方量级，使用堆的版本另作比较。若要求所有节点对，运行 N 次简单 Dijkstra 与 FW 同为 N 的三次方量级，不能把单源和所有节点对的任务直接比较快慢。 【收束提示】完整拓扑上的计算可以在控制器运行，也可以在每台路由器各运行一份。算法与部署位置不能混为一谈。
