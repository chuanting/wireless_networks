【3 分钟】 三种算法放在一起比。 Bellman–Ford：迭代的是路径的链路数，一轮多允许走一条链路；求到一个目的地；可以有负长度，只要没有负环；最坏运算量是 N 的三次方。 Dijkstra：迭代的是路径的长度，一步确定下一个最近的节点；求到一个目的地；不能有负长度；运算量是 N 的平方，比 Bellman–Ford 低。 Floyd–Warshall：迭代的是允许使用的中间节点，一轮多允许一个；一次求所有节点对；可以有负长度，只要没有负环；运算量是 N 的三次方。要求所有节点对，也可以对每个目的地各跑一遍 Dijkstra：N 次，每次 N 的平方，总量也是 N 的三次方，量级一样。 这三个算法的“迭代”各不相同，这是理解它们最简单的办法。选哪个，看网络里有没有负长度，以及要的是一个目的地还是所有节点对。
