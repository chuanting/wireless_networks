去 B　直达要 6。若走 A → C → B，要花 2 + 1。

B 改记 3，D 改记 10。两条路线的前驱都记为 C。

【3 分钟】 指图中 C 的“已定 2”。现在只处理从 C 出发、通向未确定节点的两条边。让两位同学分别负责 B 和 D。提醒他们把从 A 到 C 的 2 加进去，询问“新的路线比旧的短吗？写下新值时，最后从谁走过来的？” 等学生写完再点击。第一位把 B 的 6 改成 3，前驱从 A 改为 C。第二位把 D 的无穷改成 10，前驱写 C。前驱的意思是沿当前路线进入这个点之前的那个节点。 这时已经发现了去图书馆的路线，走 A、C、D 就能到，总价 10。问全班：就此结束，还是还值得试一条？请他们指出图上另一个尚未确定的 B，它的暂定距离才 3。下一次从它接一段，可能找到更短的路线。
