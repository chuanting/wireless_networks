长度唯一，路径不一定唯一：有并列的最短路径时，任取一条。

【3 分钟】 迭代停下来的时候，每个节点的值不再变，所以它满足 Bellman 方程：D(i) 等于所有邻居 j 的 d(i, j) + D(j) 的最小值，目的地自己是 0。这个方程说的是：从 i 到目的地的最短路径，等于第一条链路的长度，加上从下一个节点到目的地的最短路径。 有了每个节点的 D，最短路径本身怎么得到？对每个节点 i，看哪个邻居 j 使 d(i, j) + D(j) 最小，就把 j 记作 i 的下一跳。比如 A：经 B 是 2 + 7 = 9，经 C 是 4 + 7 = 11，选 B。 N − 1 个节点各选一条链路，连起来正好是一棵以目的地为根的树，右图就是它。每个节点顺着箭头走，就得到最短路径；而这就是路由表里的“下一跳”。树里每个节点旁边的数是它到 F 的最短距离。 注意：路径的长度是唯一的，路径本身未必唯一。如果有两个邻居使得右边一样小，任取一个就行。有一个前提：所有不经过目的地的环，长度都要是正的，这样才能保证选出来的“下一跳”不会成环。
