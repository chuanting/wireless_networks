【3 分钟 · 点击核对】 让一位学生在图上指出 B 的 3 怎样凑出来：A 到 C 为 2，C 到 B 为 1。上一轮已经算完，从这一轮起，所有节点都能使用这个 3。另一个学生把 B 到 D 的代价 2 接上，于是候选为 5。经 C 直接去 D 仍是 10。 为什么要把旧值 8 也拿来比较？本轮允许最多三段，因此只用两段的原路线仍然合格。如果所有新走法都更贵，我们就保留旧值。这种“试一条路线，有改进才改写”的操作称为松弛。 先让学生说出距离，再要求说出刚用的是哪条边，最后点击核对。每次改小数字时，把上一站一并记下来，下一页就能从距离还原路线。
