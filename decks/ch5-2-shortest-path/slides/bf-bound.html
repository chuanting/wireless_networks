多走 B → C → B，多付 3 + 3。删掉这两段，仍能走到 F。

每轮为什么算得全？

零段只到 F。假设上一轮算全了最多 h 段的路，新一轮保留旧路，再把每条邻边接在旧路前面，就覆盖了最多 h + 1 段的路。

怎样判断已经算完？

若通向 F 的路上没有总权重为负的回路（负环），删去回路就不会变贵。只要可达，总能找到一条最多 N − 1 段的最短路。这里 N 是节点数。
