问题

给每条链路一个长度，求最短路径；路由表的下一跳，就是最短路径的第一跳。

Bellman–Ford

每轮多允许走一条链路，最多 N − 1 轮；负长度可以，负环不行；运算量 N 的三次方。

Dijkstra

每步确定最近的一个节点；长度不能为负；运算量 N 的平方。

Floyd–Warshall

每轮多允许一个中间节点，一次求所有节点对；负长度可以，负环不行。

【2 分钟】 今天的内容一页回顾。 问题：给每条链路一个长度，求最短路径；路由表里的下一跳，就是最短路径的第一跳。 Bellman–Ford：D(i, h + 1) 等于对所有邻居 j 取 d(i, j) + D(j, h) 的最小值，每一轮多允许走一条链路，最多 N − 1 轮；允许负长度，不允许负环；运算量是 N 的三次方。 Dijkstra：每一步确定离目的地最近的一个节点；链路长度不能为负；运算量是 N 的平方。 Floyd–Warshall：每轮多允许一个中间节点，一次求出所有节点对的最短距离；允许负长度，不允许负环。 这三个都是集中式的：有一个地方掌握所有链路的长度。如果让每个节点只靠邻居也能算出来，就是下一讲的分布式路由：距离矢量是分布式的 Bellman–Ford，链路状态则是每台路由器各自跑一遍 Dijkstra。
