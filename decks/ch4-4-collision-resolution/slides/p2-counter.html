规则：计数器为 0 就发。听到 e：刚才发的（计数器为 0）抛硬币，正面仍为 0，反面变 1；其余的都加 1。听到 0 或 1：所有人减 1，成功的那个离开。

旁观者：没撞的节点只数“栈里还有几组”：开始是 1，听到 e 加 1，听到 0 或 1 减 1，减到 0，分解期结束。

表里：A、B、C 就是上一页 LL、LRRL、LRRR 里的三个分组；数字是每个时隙开始时的计数器。

一个计数器加一枚硬币，不用知道别人是谁。

【3 分钟】 每个节点怎么知道自己什么时候发？只要一个计数器，计数器的值就是“我这一组在栈里排第几”，0 表示在最上面，该发了。 规则三条： 计数器为 0 就发。 听到 e：刚才发的，也就是计数器为 0 的那些节点，抛硬币，正面仍为 0（进左子集，下个时隙接着发），反面变成 1（进右子集）；其余的节点，计数器都加 1，因为栈上面又多压了一组。 听到 0 或 1：栈顶这一组解决了，所有人减 1；成功的那个节点离开。 对照表看。时隙 1、2，A、B、C 计数器都是 0，都发，碰撞。时隙 2 碰撞后，A 抛到正面仍为 0，B、C 抛到反面变 1。时隙 3 只有 A 发，成功；大家减 1，B、C 变 0。时隙 4 B、C 发，碰撞，两个都抛到反面，变 1。时隙 5 没人是 0，空闲，减 1……一直到时隙 8 C 成功。 旁观者，比如分解期里新到的分组，只要数“栈里还有几组”：开始是 1，听到 e 加 1，听到 0 或 1 减 1。表的最后一列就是这个数，时隙 9 听到 0，减到 0，分解期结束，新分组可以发了。
