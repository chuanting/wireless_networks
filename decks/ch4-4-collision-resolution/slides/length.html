【拓展 · 4 分钟】 基础路线跳到 new，只用每个分组平均占 2.885 个时隙解释积压趋势；本页给出这一数值的递推来源。 现在算一个冲突分解期平均多长。设 n 个分组碰撞，L(n) 是到全部发完平均占的时隙数，包括最开始碰撞的那一个。 先看 n = 2。第 1 个时隙碰撞，用掉 1 个。然后两个分组各抛硬币：概率 1/4 两个都进 L：先解开 L，要 L(2) 个时隙，再加 R 的 1 个空闲时隙；概率 1/2 一边一个：两个成功时隙；概率 1/4 两个都进 R：L 的 1 个空闲时隙，再加解开 R 的 L(2) 个时隙。于是 L(2) = 1 + (1/4)(1 + L(2)) + (1/2)·2 + (1/4)(L(2) + 1)，解得 L(2) = 5。 一般的 n：左边分到 i 个的概率是二项分布 n! / (i!(n−i)! 2^n)，左右两边各自独立地解开，所以 L(n) = 1 + Σ P(i)[L(i) + L(n−i)]。i = 0 和 i = n 这两项里含有 L(n) 自己，移到左边解出来即可。从 L(0) = L(1) = 1 开始，可以一直递推下去。例如 L(3) = 23/3 ≈ 7.67。 看表：n = 2，5 个时隙，每个分组 2.5 个，通过率 0.4；n = 3，0.39；n = 4，0.38；n = 10，27.85 个时隙，0.36。n 越大，每个分组摊到的时隙越多，通过率越低。n 很大时，L(n) ≈ 2.885 n，也就是 2n/ln 2，通过率 1/2.885 = 0.347（这是文献里的渐近结果，我们用程序把 n 一直算到 400 核对过）。 这里的 n/L(n) 是“这一批恰好 n 个分组、不算新到达”的通过率，还不是系统的最大稳定通过率。下一页把到达也算进来。
