【4 分钟】 算 S(G)。一组的大小 N 服从泊松分布，N = n 的概率是 e^(−G) G^n / n!。N = n 时，解开这一组平均用 L(n) 个时隙，所以平均 E[L(N)] = Σ e^(−G) G^n / n! · L(n)，这里 L(n) 用上一页的递推（n 取到 100 足够，泊松尾部可以忽略）。 这一组对应的到达时间长度是 α0 = G/λ 个时隙。解开这一组需要 E[L(N)] 个时隙，这期间到达时间轴上又增加了 E[L(N)] 个单位。为了不积压，必须 E[L(N)] < α0 = G/λ，即 λ < G / E[L(N)]。 所以对给定的 G，能承受的最大到达率是 S(G) = G / E[L(N)]。再取 G 使它最大。看右边的表：G = 0.5，E[L(N)] = 1.40，S = 0.356；G = 1.15，E[L(N)] = 2.68，S = 0.430；G = 2，E[L(N)] = 4.86，S = 0.411。 最大值在 G ≈ 1.148，S = 0.4295：每一组平均 1.15 个分组，用 2.68 个时隙解开，每个时隙送走 0.43 个。
