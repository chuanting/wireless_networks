【3 分钟 · 本讲最漂亮的推导】 现在来求生灭链的稳态分布 π_n。用上一页“画一刀”的想法，不必解一大堆联立方程。 第一步：比如在状态 2 与 3 之间切一刀，把状态分成左右两半。稳态时，穿过这条线向右的概率流 = 向左的概率流。向右：只可能从 2 走到 3，概率流是 π_2 × p；向左：只可能从 3 走到 2，概率流是 π_3 × q。所以 π_2 p = π_3 q。切在哪一格都一样，一般写成 π_n p = π_{n+1} q。（这叫“局部平衡”。） 第二步：π_{n+1} = (p/q) π_n = ρ π_n。每往右一格，乘一个 ρ。反复代入：π_n = ρ^n π_0。 第三步：用归一化条件确定 π_0。Σ_{n≥0} π_n = π_0 Σ ρ^n = π_0 / (1−ρ) = 1（等比级数，要求 ρ < 1），所以 π_0 = 1 − ρ。 结果：π_n = (1−ρ) ρ^n，n = 0, 1, 2, …，一个几何分布。π_0 = 1 − ρ 的直观意义：服务器忙的时间比例是 ρ，所以队列为空的概率是 1 − ρ。 为什么“切一刀”可行？因为这是生灭链：左右只通过 n↔n+1 这一对箭头相连，没有别的通道。如果是一般的链，切口会有很多条边，就需要把所有边的流量加起来，这就是上一页最后讲的“流进 = 流出”。 [板书建议：写 ①②③ 三步，每步一行，留着讲下一页的数字例子。] [追问：如果 ρ ≥ 1，这个级数不收敛，意味着什么？（队列无限增长，没有稳态。）]
