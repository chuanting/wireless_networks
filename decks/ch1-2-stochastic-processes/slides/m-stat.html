稳态分布

π = (0.8, 0.2)

长期来看，80% 的时隙信道是好的，20% 是坏的。

验证

0.8 × 0.9 + 0.2 × 0.4 = 0.80，0.8 × 0.1 + 0.2 × 0.6 = 0.20：再走一步，分布不变。

频率解释：πG = 长期访问状态 G 的时间比例。

【2 分钟 · 本节核心】 上一页看到，分布最后稳定下来。现在不迭代，直接解出这个极限分布。 稳态分布 π 的定义：走一步之后，分布不再变化，即 π = πP；并且概率之和等于 1：Σπᵢ = 1。 例（信道）：设 π = (π_G, π_B)。π = πP 逐个分量写出： π_G = 0.9 π_G + 0.4 π_B（来自 G 的和来自 B 的）； π_B = 0.1 π_G + 0.6 π_B； 再加上 π_G + π_B = 1。 第一式移项：0.1 π_G = 0.4 π_B，所以 π_G = 4 π_B；代入 π_G + π_B = 1，得 5π_B = 1，π_B = 0.2，π_G = 0.8。稳态分布 π = (0.8, 0.2)——和上一页迭代出来的极限一模一样。 验证：(0.8, 0.2) 乘以 P：0.8×0.9 + 0.2×0.4 = 0.80；0.8×0.1 + 0.2×0.6 = 0.20——分布不变。 频率解释：π_j 也是“长期来看，访问状态 j 的时间比例”。所以，信道有 80% 的时隙是好的。 [注：两个方程其实有一个是多余的（第二式可由第一式和归一化条件推出），所以必须加上归一化条件才能解出唯一解。]
