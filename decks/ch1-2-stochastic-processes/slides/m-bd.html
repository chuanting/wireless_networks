生灭链：每一步只能“生”（+1）或“灭”（−1）一个，只会走到相邻状态。排队系统的标准模型。

【2 分钟】 介绍马尔可夫链里最重要的一类——生灭链（birth–death chain），它是排队论的基础，也是第 3 章“网络时延模型”要用的东西。 具体场景：路由器的缓冲区。状态 n = 缓冲区里排队的数据包个数，0、1、2、…… 假设每个时隙最多发生一件事：以概率 p 来一个新包，队长 n → n+1（“生”，橙色箭头）；以概率 q 发走一个包，队长 n → n−1（“灭”，深色箭头）。所以从 n 出发只可能走到相邻的 n+1 或 n−1，这就是生灭链的特征。（原地不动的概率 1−p−q 在图中略去了。） 状态 0：队列是空的，没有包可发，所以只有“生”没有“灭”。 负载 ρ = p/q：到达速度除以服务速度。ρ < 1 说明来的比走的慢，队列大体稳定；ρ ≥ 1 则队列越积越长。 提问：现在想知道“缓冲区平均有多少个包”，就需要知道稳态分布 π_n——下一页来求。 [提示：Poisson 到达 + 指数服务时间的连续时间版本就是第 3 章的 M/M/1 队列；这里用离散时隙版本，数学更简单，结论形式相同。]
