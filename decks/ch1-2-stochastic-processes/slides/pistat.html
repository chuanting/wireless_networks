【4 分钟 · 推导】 稳态分布的定义：再走一步，分布不再变化，即 π = πP，同时各分量之和为 1。 信道的例子：设 π = (π_G, π_B)。逐个状态写出方程：π_G = 0.9 π_G + 0.4 π_B；π_B = 0.1 π_G + 0.6 π_B。第一个方程移项：0.1 π_G = 0.4 π_B，所以 π_G = 4 π_B。再代入 π_G + π_B = 1，得 5 π_B = 1，π_B = 0.2，π_G = 0.8。 验证：0.8 × 0.9 + 0.2 × 0.4 = 0.72 + 0.08 = 0.80，0.8 × 0.1 + 0.2 × 0.6 = 0.08 + 0.12 = 0.20。 注意：π = πP 给出的方程组里只有一个是独立的（另一个是它的推论），必须再加上“总和为 1”才能得到唯一解。 频率解释：π_G = 0.8 是长期处于状态 G 的时间比例。上一页的收敛曲线，终点正是这个值。
