【3 分钟 · 推导】 归一化：所有状态的概率加起来等于 1。π_n = ρ^n π_0，所以 π_0 乘上 ρ^n 从 0 到无穷的和等于 1。等比级数 1 + ρ + ρ^2 + … = 1/(1 − ρ)，要求 ρ < 1（这就是稳定条件）。因此 π_0 = 1 − ρ，稳态分布 π_n = (1 − ρ) ρ^n，n = 0, 1, 2, … 这是几何分布：队长每多一个，概率就乘一个 ρ。队列为空的概率 π_0 = 1 − ρ，等于服务员空闲的时间比例。 平均队长：E[N] = Σ n (1 − ρ) ρ^n = ρ/(1 − ρ)。 注意：这是离散时间生灭链、无限缓冲区的结果；有限缓冲区时尾概率 ρ^K 不能直接当作丢包率，第 3 章会专门讨论。
