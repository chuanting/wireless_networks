正常：不可约 + 非周期

任何状态都能到达任何状态，也不会按固定节拍绕圈 → 稳态分布存在、唯一。

可约：有“孤岛”

蓝组出发永远到不了橙组 → 稳态不唯一，取决于从哪出发。

周期：严格交替

分布在 (1, 0) 与 (0, 1) 之间来回跳 → 不收敛。

状态有限 + 不可约 + 非周期 ⟹ 稳态分布存在、唯一，且从任何初始状态出发都收敛。本课默认满足。

【1.5 分钟 · 时间紧可以跳过】 前面的推导隐含了一个假设：稳态分布存在，而且唯一、从任何地方出发都收敛。这并不是对所有马尔可夫链都成立，需要两个条件： ① 不可约（irreducible）：任何一个状态都能（经过若干步）到达任何另一个状态。反例（中间图）：状态 1、2 和状态 3、4 是两个互不相通的“孤岛”，从一边出发永远去不了另一边，稳态分布就不唯一，取决于从哪个岛出发。 ② 非周期（aperiodic）：不存在“只能每隔固定步数才能回到某状态”的现象。反例（右图）：0 与 1 严格交替，概率 1 地来回跳，从 0 出发，奇数步在 1、偶数步在 0，分布永远在 (1,0) 与 (0,1) 之间切换，不收敛。（虽然 π = (0.5, 0.5) 仍满足 π = πP，但“长期分布”不是它。） 左图是正常情形：三个状态两两互通，也没有固定节拍。 结论：状态有限的链，只要不可约、非周期，稳态分布就存在、唯一，并且无论从哪个状态出发，分布都会收敛到它。本课讨论的信道、队列例子都满足。 [提示：学习通信网络，只需要记住“实际的网络模型通常满足这两个条件”。]
