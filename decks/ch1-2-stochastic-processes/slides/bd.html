状态 n 是缓冲区里排队的数据包个数。每个时隙至多发生一次变化：以概率 p 来一个（n 加 1），以概率 q 走一个（n 减 1），其余时候原地不动，所以 p + q ≤ 1；队列为空时只能来、不能走。

ρ = p / q

到达快慢除以服务快慢。要求 ρ < 1，队列才不会无限增长。

生灭链：每步只能“生”（+1）或“灭”（−1），只走到相邻状态。排队系统的标准模型。

【3 分钟】 一类重要的马尔可夫链：生灭链。用它描述路由器的缓冲区。状态 n 是缓冲区里排队的数据包个数。 离散时间的版本这样规定：每个时隙至多发生一次变化。以概率 p 来一个包，n 加 1；以概率 q 走一个包，n 减 1；其余时候原地不动，因此要求 p + q ≤ 1。队列为空时只能来、不能走。图里省略了原地不动的自环。 ρ = p/q：到达快慢除以服务快慢，叫负荷（利用率）。要求 ρ < 1：到达比离开慢，队列才不会无限增长。 生灭链每一步只能加一或减一，只走到相邻状态，所以结构非常简单，下一页只要“切一刀”就能把稳态分布解出来。这个模型的连续时间版本，就是第 3 章要研究的 M/M/1 队列。
